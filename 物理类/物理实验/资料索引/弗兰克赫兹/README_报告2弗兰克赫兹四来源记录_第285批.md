# 报告2中的弗兰克—赫兹四来源记录

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人原有副本。本次补入最后一份13页手写填写稿，含封面、原理步骤、数据处理、结论思考、私人总结、两页手写原始记录与末页仪器打印图。

本来源目录内四个同题名原路径均已有可恢复去向，共12,820,340字节、45文件页、4个不同哈希。证据为上一批3份与本批1份，本地四份哈希重新核对；历史3份复核的是已保存的云盘字节，并非四份本次全部重新下载。不同来源整件保留，不称四个独立报告或新版。只有上一批8页件表头标明物理A(2)，该标注不推广到其它件。报告2其余47份资料不在这组记录范围内。
