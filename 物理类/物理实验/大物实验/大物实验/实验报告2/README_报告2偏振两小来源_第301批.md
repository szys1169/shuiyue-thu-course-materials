# 偏振两份小来源的新位置

两份共31页的偏振光学手写填写报告已保留原名原字节归入私有学习目录，含原理、测量数据、思考、曲线和原始记录与纸面批改。私人身份、评价和日期不在说明中转录；打印曲线、身份原始记录纸和全部附页仍保持，不裁剪或修订答案。

只整理本次两份小来源，来源编号不证明版次先后，也不证明独立报告或授课学期。另31份原件（包括另外两份偏振题名资料）保持原位。
