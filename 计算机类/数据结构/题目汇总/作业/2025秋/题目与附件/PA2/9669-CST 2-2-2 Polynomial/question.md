# CST 2-2-2 Polynomial

---

### **题目描述**

大 R 的妹妹小 R 上初中了，学到多项式部分的时候老师经常出一些很复杂的一元多项式展开的题，即对老师给出的涉及多种运算的多项式，最终要写成多项式的标准形式： n∑i=0aixi \sum_{i=0}^{n}a_ix^i

小 R 算出结果后不自信，总是要找大 R 检查。在多次被当“人脑计算器”使后，大 R 决定找到在星期四大学上数据结构的同学发挥编程特长，写一个程序一劳永逸地帮妹妹解决这一问题。

首先，我们可以递归地定义关于变量 `x` 的“多项式”：

- `x` 是多项式
- `[1, M)` 内的每个正整数也是多项式
- 如果 `A` 和 `B` 是多项式，那么 `A+B`、`A-B`、`A*B`、`(A)`、`A^k` 也是（kk 为正整数）

你的任务是将老师给的多项式展开，转换为多项式的标准形式。但毕竟小 R 不是程序员，她的输入可能不会符合程序员的严格风格，而更贴近书写习惯，因此你的程序需要充分考虑小 R 的输入习惯与老师的要求。

- 小 R 不喜欢在运算符两侧加上空格，因此你得到的输入是没有冗余空格的紧凑字符串；
- 涉及到的运算符包括加号 `+`、减号 `-`、乘号 `*`、次幂号 `^`、小括号 `()`。好消息是，在多次交涉后，小 R 终于同意了只使用小括号来表示嵌套，因此你不会见到中括号、大括号等其他类型的括号，运算符之间的优先级顺序与[讲义](https://dsa.cs.tsinghua.edu.cn/~deng/ds/src_2025/evaluate/priority.h.htm)一致，尤其需要注意的是，次幂号 `^` 为左优先结合；
- 多项式中的变量统一为字母 `x`；
- 次幂号的右边一定是正整数；
- 括号内部不为空；
- 数值总是最高位不为 00 的正整数（于是 00 和负数不会作为系数出现，但不要忽略减法）；
- 某些情况下小 R **可能**会偷懒省略乘号，但仅限于如下几种情况：  紧靠于乘号右边的是左括号； 紧靠于乘号右边的是 `x`，同时左边不是 `x`（比如 `3(2+1x)x*x` 是合法的，而且最后那个乘号不能省略）；
- 除了乘号可能省略，小 R 保证输入内容绝对是合法多项式，绝不会出现未定义的表达式，比如 `x^(3)`（次幂部分不应出现运算符）或 `(1+(2x+3)`（括号失配）之类。
- 标准形式多项式中的系数可能非常大，为便于老师检查这里统一约定，每个系数都需要对一个固定的正整数 `M` 取模，转换为 `[0,M)` 内的一个整数。  特别地，若取模后最高位为 0，则该位不需要输出。例如 P(x)=Mx2+(M+1)x+1≡x+1(modM)P(x) = Mx^2+(M+1)x+1 \equiv x+1 \pmod M，故只需输出多项式 x+1x+1 对应的系数。

### **输入**

只有一行字符串，所有字符均取自 `0123456789x-+*^()`，末尾以 `\n` 结束。

### **输出**

如果是 kk 次多项式，你就需要按照次数由高到低地输出 k+1k+1 个各项系数，以空格相隔。

特别地，如果结果为 00，则直接输出 `0`。

### **输入样例**

```
((2)*x*x+1)^2-(2x^2)^1^2^1-3x^3
```

注：此样例是第 11 个测试点。

### **输出样例**

```
1000000004 4 0 1
```

### **样例说明**

(2x2+1)2−(2x2)2−3x3=−3x3+4x2+1≡1000000004x3+4x2+1(modM) (2x^2+1)^2-(2x^2)^2-3x^3=-3x^3+4x^2+1\equiv 1000000004x^3+4x^2+1 \pmod M

### **数据范围**

输入字符串的长度 0<n≤10000000 < n \le 1000000

次幂号右边的正整数 k≤4k \le 4

正整数 M=1000000007M = 1000000007

正常计算过程中最高项次数 m≤64m \le 64

### **资源限制**

时间限制：1.5 s

内存限制：256 MB

**本题允许使用STL**

### **提示**

- 中缀表达式求值
- 注意比较 M×MM \times M 与 int、long long 的上限。
- 快速幂可能会在某些情况下优化你的程序效率，但这不是本题考察的内容。
