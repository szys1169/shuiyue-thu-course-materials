# 传热设备与技术：孟继安课件来源

来源：[黄逸洋public的传热设备与技术目录](https://cloud.tsinghua.edu.cn/d/cc494ee97f884a3b9ffb/?p=%2F2.6_%E8%83%BD%E6%BA%90%E5%8A%A8%E5%8A%9B%E7%B1%BB_%E4%BC%A0%E7%83%AD%E8%AE%BE%E5%A4%87%E4%B8%8E%E6%8A%80%E6%9C%AF&mode=list)，原上级文件夹名为“传热设备与技术_复习笔记_马逸”。按正文实际角色，本组是《强化传热技术与传热设备》教学课件及相关工程案例，共21份PDF与1份PPTX；首页公开署名孟继安。文件名的2019沿原样保留，正文另有较早日期，未统一改写为单一授课学期。

内容从导热、对流换热的强化、沸腾凝结，到换热器与余热回收、热管等工程应用。同主题PDF与PPTX是不同字节原件，均保留。教师在课件中公示的教学联系保留原件，不转抄进说明；专利号、工程表格连串数字不是学生编号。

文件原名、图表、字节保持。仅排除来源.DS_Store系统文件，未执行幻灯对象或宏。逐件SHA见同目录来源清单。
