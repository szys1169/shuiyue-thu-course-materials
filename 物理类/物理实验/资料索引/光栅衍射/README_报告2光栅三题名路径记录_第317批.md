# 光栅衍射三条原题名来源路径

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本批末一份为8页彩色照片填写稿，含原理图示、实验步骤、测量与误差分析、分辨率数据、思考题及原始记录。

原件连同纸面批注、划改数据、照片阴影和页边完整云盘保存，本批未新增入Git。身份、私人日期和评价不在说明中转录；编号沿原题名，作者、学期待核。

三个原题名路径均有去向记录，共28,745,365字节、25文件页、3个不同SHA。前两件沿用第287批已验来源与已保存云盘字节，本批新回取末一件，本地三件重新核对哈希。此账记录原路径去向，编号不作为版次或独立报告数量。报告2另19份原件保持原位。
