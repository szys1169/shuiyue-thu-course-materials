## 前言

现在ai非常热门，大家都知道ai非常好用，但由于vpn等各种各样的问题，我身边仍有不少朋友只使用deepseek网页端。我最近帮助不少朋友配置了codex，也向我的不少朋友推荐了codex。

配置并非一个非常简单的事情，我自己配置时也花了不少功夫。线上帮别人配置，也还是有些麻烦。于是便有了本文档的诞生，在本文档我们会介绍，为什么要用codex，怎么下载codex，如何使用codex，以及付费等相关问题。

最后为了照顾完全不了解的朋友，这里给一些名词解释：

- API：软件之间互相发送请求和返回结果的一套接口。网页聊天是人在页面里直接输入内容，API 则可以让 Codex、脚本或其他软件自动调用模型。

- API Key：平台发给用户的一串调用凭证，作用有点像密码。平台会用它识别账号、额度和计费信息，所以不要把真实 Key 发到群聊、截图或公开仓库里。

- 智能体/Agent：不只是回答问题，还能根据目标读取上下文、调用工具、修改文件、运行命令，并连续完成多步任务的 AI。

- Skill/技能：给智能体使用的一套可复用说明，里面可以规定某类任务的流程、格式、注意事项和参考材料。它更像一份专门的工作手册，并不是一个新的模型。

## 一、Codex 是什么

简单来说，Codex 是一个可以真正进入项目里干活的 AI 助手。

普通聊天机器人更多是在对话框里给建议；Codex 则可以在你授权的文件夹中阅读代码和文档、修改文件、运行命令、检查报错、执行测试，并把较长的任务持续做下去。它可以通过桌面应用、IDE 扩展和命令行使用。

在课程学习和科研项目里，它比较适合做这些事：

- 阅读课程代码，解释某一段到底在做什么；
- 帮你定位编译错误、运行错误和测试失败；
- 整理实验项目、讲义、笔记和 README；
- 为科研代码补测试、写使用说明、复现实验流程；
- 把一项大任务拆成计划，再逐步执行和验收。

不过它不是“自动正确机”。尤其是数学证明、课程作业和科研结论，最后仍然需要自己检查。我的理解是，可以把它当成一个很能干、但偶尔会非常自信地说错话的队友。

## 二、为什么要用codex

我身边的朋友，不使用codex等本地ai软件的理由通常是下面几种：

- 1.没有vpn/不愿翻墙
- 2.不愿使用国外ai
- 3.我又不写代码，为什么要用这些ai

我个人在之前其实是1和3的结合体，下面我会给出我的看法

- 1.这是一个绝妙的借口，以“我不翻墙/我没梯子”为借口，拒绝接受新事物）但翻墙其实并不困难，最多就是每月十几块罢了，而且只要不鉴证没人管你
- 2.可管理本地的agent软件也并非只有国外的，不接受国外ai为何不用国内的deepseek harness等agent呢
- 3.这些本地agent的能力远非写代码，相比网页端的ai，ta能极大提高工作效率

此外，很多需求是你用了这些agent之后才会出现的，比如生一份复习ppt，做一些skill之类。

我理解下，这些agent可以**把每个人的计算机能力极大的拉高**，不少事情之前门槛很高，codex这类agent极大的降低了门槛，比如从github上给本地部署使用一些项目，对于电脑小白，之前可能需要查攻略一步一步对着做，现在只需要和codex说一句话就好了。这类agent，把很多事情“我知道它”和“我能做它”画上了等号，而且还极大的提高了效率。

比如我最近想买一个电脑插件，之前我需要到系统里面去查我电脑本身的配置，但是现在我只需要向codex提问，我便能知道我买内存的话需要买什么型号的（是的，实在等不及内存降价了，我早买早享受了）


## 三、下载

### 1. 网络与 VPN

这一步并非困难，我相信你们可以自己解决。

这里特殊说明一下：**我不会在这篇公开攻略里提供 VPN 服务、节点或购买链接。** 这类信息大规模传播存在法律、校规和账号安全风险。请遵守所在地法律法规；确有需要可以私信询问，或者先问自己信任的学长学姐。

在这一步会有一些常见问题，我这里一一回答：

- Q:科学上网（翻墙）违法吗？ A:不鉴证就没人管你
- Q:朋友给我的梯子要收费，选择什么价格的？ A:最便宜的
- Q:vpn的节点选哪里？ A:默认的一般就行，如果哪里出了意外换美国

### 2. ChatGPT 的账号注册

科学上网后，直接搜索ChatGPT，找到官方网站，直接注册即好，这里没什么卡人的地方，唯一需要注意的是最好别使用学校邮箱，用自己qq邮箱注册即可

ChatGPT 官方登录与注册页面：<https://chatgpt.com/auth/login>


### 3. Codex 的下载

最近一次更新codex已经改名叫chatgpt了。科学上网后搜codex，直接下载即可，windows点击安装包之后会跳转到微软商店，这是正常现象，无需担心。

ChatGPT/Codex 官方下载页：<https://chatgpt.com/download/>

第一次安装可以按下面做：

1. 打开官方下载页，选择自己的系统；
2. Windows 跳转到 Microsoft Store 后点击安装；
3. 安装结束后打开 ChatGPT 桌面应用；
4. 登录后从左上角进入 Codex。

除了桌面应用，也可以使用 [Codex CLI](https://learn.chatgpt.com/docs/codex/cli) 或 [VS Code 的 Codex 扩展](https://learn.chatgpt.com/docs/codex/ide)。第一次接触这类工具的话，先用桌面应用就够了。


### 4. Codex 登录

本地使用 Codex 时，主要有两种官方登录方式：使用 ChatGPT 账号登录，或者使用 OpenAI API Key 按量调用。我们一般使用前者登录。

使用前面注册的账号即可，这里需要注意的是登录codex的时候可能需要手机号验证码，这里不支持国内的手机号。

一般我们的解决当时是通过接码平台，这里我会提供一个，大家也可以和自己的朋友要，如果有比我这个好的可以分享给我：

https://hero-sms.com/cn/purchases/numbers?tab=sms

这是第三方服务，不属于 OpenAI。使用前请自行确认服务条款、隐私风险和账号风险，不要把 ChatGPT 密码交给平台。

账号准备好后，打开桌面应用，点击登录并在浏览器中完成授权，之后回到应用进入 Codex。官方支持使用 ChatGPT 账号获得订阅访问，也支持使用 OpenAI API Key 按量访问。前者对第一次使用的读者更直观。

Codex 登录与认证说明：<https://learn.chatgpt.com/docs/auth>

### 5. 充值

进行这一步前建议先读完本文的第五部分。

充值这里可能遇到的问题是，codex的充值需要国外银行卡，但显然这个东西不太好获得，所以我们的方式是使用代充平台。

类似前面，我会提供一个，大家也可以和自己的朋友要，如果有比我这个好的可以分享给我：

https://getgpt.pro/

这同样是第三方服务，不属于 OpenAI。实际价格、到账方式和售后规则可能变化，建议先小额测试，也不要向代充方提供邮箱密码或完整 API Key。

这里一定要分清楚：ChatGPT 订阅、OpenAI API 余额和第三方 API 平台余额是三套东西。在 ChatGPT 中开通套餐，不等于 OpenAI API 账户里有余额；给并行智算云或 DeepSeek 充值，也只能在对应平台使用。

ChatGPT 套餐页面：<https://chatgpt.com/pricing/>

OpenAI API 充值页面：<https://platform.openai.com/settings/organization/billing/overview>

如果使用本文后面介绍的第三方 API 方案，就不需要再给 OpenAI API 账户充值。需要充值的是你实际获取 API Key 的平台，余额也只能在对应平台内使用。第一次充值时建议先充少量，确认 Codex 能正常调用后再继续。

## 四、如何接入其他 API



进行这一步前先完成第三部分的安装和账号准备，建议先读完本文的第五部分。

下面分别介绍我写的切换脚本、CC Switch 和 DeepSeek 官方脚本。三种方法不需要同时配置，选一条适合自己的路线即可。

### 方案一：清华算力卷 + 我写的接入脚本

这是我更推荐的方案。完整流程分成三部分：先领算力券，之后在并行智算云获得 API Key，最后用脚本把它接入 Codex。

#### 第一步：领取算力券

1. 打开[算力券申领平台](https://easycompute.cs.tsinghua.edu.cn/login)；
2. 通过清华大学统一身份认证登录，使用自己的学号或工作证号；
3. 登录后点击“登录领券 / 使用”按钮；
4. 算力券会自动发放到个人账户，可以在“我的优惠券”中查看和使用。
5. 点击使用后会跳转到并行智算云
6. 在顶部“大模型平台-API密钥”中新建api key


#### 第二步：用脚本接入 Codex

如果你是从我的云盘点开的文档，脚本就在本档旁边，也可以从云盘下载：<https://cloud.tsinghua.edu.cn/d/c52cc8b195b240dd87a9/>

由于学校发了1000元算力券，基本免费，所以我更推荐先试它。但这个较为难用，这也不是长期免费的承诺，具体额度仍以账户中的优惠券和平台规则为准。

脚本具体操作如下：

1. 下载 `codex-api切换.zip`，右键选择“全部解压缩”；
2. 保存当前工作，再完全退出 ChatGPT 桌面应用或正在运行的 Codex；
3. 打开解压后的文件夹，双击 `启动Codex切换.bat`；
4. 第一个菜单输入 `2`，选择并行智算云；
5. 第二个菜单输入 `1` 或 `2`，选择要使用的模型；
6. 第一次使用时粘贴刚才复制的 API Key，然后按回车；
7. 看到 `[OK] 已切换到并行智算云` 后关闭窗口；
8. 重新打开 Codex，先发送一个很短的测试任务。

输入 Key 时窗口不会显示文字或星号，这是正常现象。可以用下面这句话测试：

```text
请只回复“连接成功”，不要读取或修改任何文件。
```

能够正常返回结果，基本就说明接入成功。桌面应用中的模型名称可能显示为具体模型名，也可能显示为 `Custom`。

如果想恢复 Codex 原版，重新运行脚本，在第一个菜单输入 `3`，看到成功提示后重启 Codex 即可。脚本每次切换前都会备份原来的 `config.toml`。

更完整的 Key 保存位置和故障恢复方法写在工具文件夹的 [README](./codex-api切换/README.md) 中。

这个方案也可以接入deepseek官方api key

## 五、关于费用的一些问题

我相信不少看这篇文档的朋友可能还抱有着互联网上的东西就要白嫖的态度，所以不太愿意为本文所提到的vpn，中介平台，api以及codex官方付费（）

### 1.使用 Codex 一定要充值吗

不一定。主要有下面几条路线：

- 使用包含 Codex 额度的 ChatGPT 套餐；
- 使用并行智算云、DeepSeek 等第三方 API，消耗对应平台的余额或算力券。

如果能够领取校园算力券，可以先试并行智算云，不需要一开始就充值。

### 2.新手推荐如何使用

我记得有免费的额度，建议可以先试用一下。如果一开始有些小任务可以先接学校的算力卷，那个虽然不好用但是免费，如果一个月以内需求很大的话可以考虑充值chatgpt的code plan

### 3.有必要充值plus吗

如果你的需求够大，能一个月内用掉plus额度的80%以上，那我认为plus还是很划算很值得的，20美刀一个月换生产力的巨额提升

### 4.国内模型和gpt5.6有很大差距吗

如果不使用过于专业的功能，比如大规模写代码，数学研究等，大家的体感差距基本不大，所以可以放心接入国内模型



## 六、如何使用codex

一些常规的场景无需我多说，比如写作业，做项目，那本节的主要内容在于，如何把codex，覆盖到更多的领域，或者如何增强它的能力

### 1.善用github

github上有许许多多有趣的项目，说不定就能对你有所帮助，在干一些事情的时候不妨让你的codex先去github上找找有没有什么开源项目，当然别忘了，如果真有用的话给一个star

### 2.重复的事，做一个skill

如果一件事只做一次，在对话里把要求说清楚就够了。但如果同一种任务会重复出现，比如每周整理作业、把讲义转成复习提纲、按固定格式检查代码，或者统一一批文档的语言风格，每次从头解释一遍就很浪费。这时可以把流程做成一个 Skill。

简单来说，Skill 就是给 Codex 的一份长期工作说明。里面可以写清楚什么时候应该使用它、需要读取哪些材料、按什么顺序做、哪些东西不能改，以及最后怎样才算完成。之后再遇到同类任务，Codex 就可以沿用同一套规则。

第一次做 Skill 不需要自己研究文件结构，可以直接对 Codex 说：

```text
我经常需要完成下面这类任务：
【在这里描述任务】

请先阅读本机中与这项任务有关的材料，总结固定流程、输出格式、禁止事项和验收标准，
然后为它创建一个可复用的 Skill。创建完成后告诉我它保存在哪里，并用一个最小示例测试。
```

描述得越具体，Skill 越好用。至少建议写清下面几件事：

- 什么时候调用，例如“当我让你整理课程资料时使用”；
- 输入从哪里来，例如当前文件夹、指定讲义或聊天中粘贴的内容；
- 固定步骤是什么，例如先分类，再提取重点，最后生成目录；
- 哪些事情不能做，例如不要擅自删除原文件，不要修改数学结论；
- 输出放在哪里，以及需要 Markdown、LaTeX 还是其他格式；
- 如何检查结果，例如链接能否打开、代码能否运行、文档是否还有空缺。

Skill 适合处理规则稳定、会反复出现的工作，不适合把每一次临时要求都塞进去。做完后先拿一个小任务测试，发现它理解错了，就让 Codex 根据这次错误修改 Skill。这样迭代几次，通常会比写一段很长的万能提示词更可靠。

### 3.发挥创造力

我们往往能在视频平台看到一些很有意思的东西。而现在，我们不仅仅只能看着，我们也能去创造。虽然codex只能降低一些编程的门槛，不至于让我们一个人零基础就能手搓一个大型项目，但小一点的项目我们还是可以许愿得到的。

比如你想做一个植物大战僵尸的奇怪版本，又或者是杀戮尖塔的一个mod，还是什么作业发布在网络学堂后ai自动解决的agent，亦或者是全自动刷新二游日常的agent，只要你想，再付出一点token和精力，这些我们自己都能实现

## 七、使用ai的边界

前面提到了很多ai有多强，多好用，现在我们要提出另一个问题，什么时候，不该用ai？

### 1. AI不能替你学习

完成作业和学会知识其实是两件事。ai可以在几分钟内生成一份看起来很完整的答案，但如果自己连题目在问什么都没有弄清楚，那么作业虽然交上去了，能力并不会因此增加。

我认识不少朋友，他们在一场较难的编程考试中得了零分，究其原因，ai用的太好了，平时作业全都是ai写的，所以自己什么都不会。

确实，有些课程，在现在的ai时代已经失去了学习的价值，但如果一味的用ai完成作业，怕是有意义的课也学不会什么东西，考试也容易挂科。

另外一方面，有些作业看起来是一些重复性劳作，从中我们能获得直觉和经验，如果用ai代替完成，后续的内容也很难理解。

我们不得不正视一个问题，在新的时代，我应该学会什么，如何用ai辅助我学习，而不是ai代替我学习


### 2. AI给出的结论要检查

ai会犯错，而且有时会把错误的内容说得非常确定。代码可能能运行但逻辑是错的，数学证明可能在某一步偷偷使用了没有证明的结论，引用和网址也可能根本不存在。

所以不同任务要有不同的验收方式：

- 代码至少要运行测试，并检查输入边界和错误处理；
- 数学题要逐步验算，确认每个定理的条件都满足；
- 论文和报告中的引用要打开原文核对，不能只看标题像是真的；
- 涉及费用、政策、软件版本和平台规则时，要回到官方网站确认；
- 医疗、法律、财务和实验安全等重要问题，不能把ai当作最终决定者。

一个很好用的习惯是，完成任务后另开一轮检查，让ai专门寻找错误，而不是继续证明刚才的答案是对的。不过ai自查仍然只是辅助，最后还是需要自己验收。

我赞成一句话，**虽然任务是ai完成的，但为之负责的，还是人本身**（我瞎编的）

## 八、一些ai4math的题外话/碎碎念

这一部分主要写给数学的同学。

最近ai做出来不少数学成果，引发了数学界的一波波“震荡”。这个事情很有意思，有点像ai之前在代码界带来的变革一样。

### 1. 态度

数学界对于ai的态度大抵有两种，至少在网上看起来主要是这两种，一种是悲观的，认为马上ai就将完全取代数学家了，现在出的成果越来越多，越来越快，越来越重量级，另一种则是乐观的，认为现在的成果属于小概率抽卡事件，ai的数学能力还没那么夸张，我们的数学还大有可为。

悲观派的代表人物有许多，比如那个分析学爱好者；而乐观派我认识的也不少，目前我身边不少数学的同学，老师还是乐观的。

此外还有一些很有意思的东西，不少群聊里的群友，听他对话并非数学专业，也并非尝试过ai4math，便夸下海口，给他多少token，他必做出来一篇四大；也有一些人，明确表示自己不会使用国外的ai，何时国内有了能力强的自己再用。

### 2.审核&负责

ai在math领域带来的令一波冲击是论文的审核，现在在ai的帮助下，数学论文的产出越来越快，与之带来的直接后果就是人类审核不过来了。

其实本来数学界的审核效率就不高，审核几乎算是一个自愿的工作，而数学论文又晦涩难懂，不像其它学科可能只需要做一个实验复现就好了，难一点的论文的审稿周期可能是按年计的。

而过去，成果好歹是人做的，现在，可能成果是ai自动跑出来的，只有ai自己懂。许多不负责任的研究员，只负责用ai产出，自己不看，不管最终成果是否正确，浪费了大量的数学家精力。难以想象不远的将来，数学论文开始井喷后人类数学家会如何应对，全盘相信lean吗？

现在数学家们呼吁，论文的署名者者不包括ai，署名的人要对论文负责。但如果未来ai的数学能力再度迎来飞升，这一套约定还真的能继续下去吗？
