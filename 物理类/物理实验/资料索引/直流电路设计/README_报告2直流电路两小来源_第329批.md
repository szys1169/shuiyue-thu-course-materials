# 直流电路设计的两份来源

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本，共两份PDF、6,833,432字节、23文件页。

14页件含填写封面、原理仪器步骤、数据处理、思考题、个人总结和两页原始记录；9页件含原理仪器、数据处理、思考题和末页原始记录。内容涉及电表改装、内阻测量、校准与直流电路设计，按实际正文归入本主题。

原件连同批注、附页和原始记录完整云盘保存，本批未新增Git。身份、私人日期及评价不在说明中转录；编号沿原题名，作者、学期待核。报告2另9份原件（含两份较大直流设计来源）仍在原位。
