# 瞬态第二原题名来源

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本份PDF为30,960,178字节、11文件页，含仪器、传输线与超声原理方法、原始记录、拟合图、数据处理及个人总结。

原件连同批注、照片阴影、页边和附页完整云盘保存，本批未新增入Git。身份、私人日期及评价不在说明中转录，编号沿原题名，作者、学期待核。

本组仅整理这一条来源路径，另一较大的瞬态来源仍在原位。报告2另12份原件保持原位。
