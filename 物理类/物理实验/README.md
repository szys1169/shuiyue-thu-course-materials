# 大学物理实验资料入口

这里汇集课程资料、实验方法、参考阅读，以及不同来源的历史实验报告、测量记录和图表。已核的历史实验报告来源为共享物理资料库及本人既有副本；其它来源未明的材料，以分组说明或待核标注为准。作者、学期、材料日期与版本详见对应说明。

## 按用途查找

- **课程资料、讲义**：查找课程相关说明、实验方法与参考材料，先看分组介绍。
- **往年题**：查找历史题目及来源记录，课程与年份以题面和来源说明为准。
- **参考阅读**：按需要查阅补充材料。
- **资料索引**：按实验主题查找来源说明，了解不同填写稿、测量记录和附页的归档去向。

以上为现有类别。名称相近的文件可能包含不同填写、图表或混合附页，可先通过下面的来源导航判断用途。
