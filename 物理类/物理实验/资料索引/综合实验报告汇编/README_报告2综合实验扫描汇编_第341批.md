# 综合实验报告汇编来源

来自共享物理资料库“实验报告2”及本人旧副本，原题名为“大物实验报告整理版.pdf”，共438页、15,456,500字节。它是包含多种主题的已填写、批改实验报告扫描汇编；编者、完整内容目录及整组课程学期待核。

实际查看了第1、2、3、4、19、81、219、438页，共8页；其余页面只核对PDF结构元数据，未逐页查看。抽样所见涉及空气比热系数、塞曼、电表测量与传输线，末页为横向拟合图。不能据此认定全书完整或计算正确。

现有两个书签中，“塞曼”指向第19页，与抽样内容相符；“迈克尔孙”指向第81页，该页实际为电表测量材料，书签不宜作为可靠的完整目录。

原字节、全部438页顺序、手写批改、原有黑块、页边和横向图表整体保留，不拆分或修复书签。抽样页可见身份及评价字段，本文不转录具体值。原件云盘保存，本批不新增Git。
