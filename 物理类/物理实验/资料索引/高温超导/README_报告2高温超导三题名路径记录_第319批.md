# 高温超导三条原题名来源路径

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本批末一份为15页填写稿，含高温超导临界转变温度测量的原理、仪器、方法、横向数表、打印曲线与拟合说明，以及思考题和个人总结。

原件连同批注、附页、黑色噪点、遮挡和页边完整云盘保存，本批未新增入Git。身份、私人日期及评价不在说明中转录，编号沿原题名，作者、学期待核。

三个原题名路径均有去向记录，共22,463,103字节、48文件页、3个不同SHA。前两件沿用第289批已验来源与已保存云盘字节，本批新回取末一件，本地三件重新核对哈希。此账记录路径去向，编号不作为版次或独立报告数量。报告2另18份原件保持原位。
