# 单色仪吸收曲线四题名来源去向

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本批末一份为9页彩色照片填写稿，含原理与步骤、测量数据、结论误差、思考题、两页原始数表及打印吸收曲线。

原件连同纸面批注、曲面阴影、页边和附页完整保存；原件云盘保存，本批未新增入Git。身份及私人日期不在说明中转录，编号与空格沿原题名，作者、学期待核。

四个原题名路径均有去向记录，共34,566,289字节、49文件页、4个不同SHA。前三份沿用第309批已验来源与已保存云盘字节，本批新回取末一份，本地四件重新核对哈希。此为路径去向账，编号不代表版次或独立报告数量。报告2另23份原件保持原位。
