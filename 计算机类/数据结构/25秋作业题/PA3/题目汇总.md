# CST 3-1-1 History

---

### **题目描述**

邓公想要了解同学们的做题进度，于是他会截取一段时间的提交记录来看，一个提交记录其实就是一个整数型的学生 id，唯一代表了一个学生。假如两个学生 id 相同，就代表是同一个学生提交的。

邓公每看到一个记录，就会问一下你，该同学上次提交是什么时候。如果这次是第一次提交，你则要回答当前时刻。

### **输入**

第一行输入一个正整数`n`，表示共有`n`个提交记录。

接下来`n`行，每行一个非负整数，第`i`个整数表示第`i`次提交的学生的id。**注意，该 id 并非真正的学生 id，你应该将id与上一次询问的答案做异或，才能得到真正的学生 id。特别地，第一次询问时的“上一次询问的答案”是 0。**这是为了体现“在线查询”，确保得出答案后才做下一次查询。

### **输出**

输出`n`行，每行一个正整数，第`i`个整数表示第`i`个提交记录的学生上次提交时间，所谓上次提交时间即该学生上次提交的提交记录是第几条。**另外，如果该学生是第一次提交，输出`i`即可。**

### **输入样例**

```
8
14
15
15
10
12
12
11
11
```

### **输出样例**

```
1
1
2
4
4
5
3
6
```

### **样例解释**

第一个输入是 14，上次答案是 0，所以第一个学生是 14，之前未出现过，所以第一组询问答案为 1。

第二个输入是 15，上次答案是 1，所以第二个学生是 14，上次出现是第 1 条记录，所以第二组询问答案为 1。

第三个输入是 15，上次答案是 1，所以第三个学生是 14，上次出现是第 2 条记录，所以第三组询问答案为 2。

第四个输入是 10，上次答案是 2，所以第四个学生是 8，之前未出现过，所以第四组询问答案为 4。

第五个输入是 12，上次答案是 4，所以第五个学生是 8，上次出现是第 4 条记录，所以第五组询问答案为 4。

第六个输入是 12，上次答案是 4，所以第六个学生是 8，上次出现是第 5 条记录，所以第六组询问答案为 5.

第七个输入是 11，上次答案是 5，所以第七个学生是 14，上次出现是第 3 条记录，所以第七组询问答案为 3。

第八个输入是 11，上次答案是 3，所以第八个学生是 8，上次出现是第 6 条记录，所以第八组询问答案为 6。

### **数据范围**

1 <= n <= 1,000,000。

每条提交记录所输入的所有数字都是小于 2^30 的非负整数。

# CST 3-1-2 Dance

---

### **题目描述**

在苏格兰舞会上，人们会**围圈**跳舞，并由主持人带领进行着队形变换。舞会期间，不断会有新人加入。主持人确定所有变换之后，希望预先知道，一曲终了时的队形将会如何。

人们在舞圈里的位置，自正门处起**顺时针地**从 00 开始逐个编号。从最初空的舞圈开始，反复做下列四种队形变换：

- IxpI\, x\, p：代号为整数 xx 的舞者，加入到舞圈中 p−1p-1 号与 pp 号舞者之间，编号取作 pp，原 pp 至 n−1n-1 号舞者的编号各自加一，其中 0≤p≤n0 \le p \le n，nn为当前的舞者总数。特别地，如果 p=np = n，则 xx 将插到 n−1n-1 号与 00 号之间，编号取作 nn，原先舞者的编号均保持不变；如果 p=0p=0，则 xx 将插到 00 号与 n−1n-1 号之间，编号取作 00，原先的所有舞者编号各自加一；
- SijS\, i\, j：ii 号舞者与 jj 号交换位置。0≤i,j<n0 \le i,j < n；
- RrR\, r：舞圈整体**顺时针**旋转 rr 人，r∈Zr \in \mathbb{Z}，舞者的编号（在模 nn 意义下）各自**增加** rr 个单位。当然，若 r<0r<0，则相当于是**逆时针**旋转，所有编号减少 −r-r 个单位；
- FijF\, i\, j：ii 至 jj 号舞者整体区间翻转，0≤i,j<n0 \le i,j <n。这里的区间是就循环意义而言的，以 n=7n = 7 为例，若舞者代号依次为 a,b,c,d,e,f,ga,b,c,d,e,f,g，则在做过 F14F\, 1\, 4 翻转后，代号序列将转成 a,e,d,c,b_,f,ga,\underline{e,d,c,b},f,g；而在做过 F41F\, 4\, 1 翻转后，代号序列将转成 f,e_,c,d,b,a,g_\underline{f,e},c,d,\underline{b,a,g}。

### **输入格式**

第一行有两个正整数：NN 为最终的舞者总数，MM 为队形变换的总次数。 接下来的 MM 行，按照上述格式逐一列出各次变换。S,R,FS,R,F 操作保证当时的舞圈不空，i,ji,j 总是当前舞圈中的合法位置。

### **输出格式**

仅一行，按最终次序逐个列出舞者代号。

### **输入样例**

```

I 4399 0
I 1024 1
R -1
S 0 1
I 7777 1
R 20
S 1 2
F 2 0
F 0 1
F 1 0
I 1111 0
I 2048 4
S 1 3
R -3
F 0 2
F 3 0
S 0 0
S 1 4
F 3 2
R 2
```

### **输出样例**

```
1024 4399 7777 2048 1111
```

### **限制**

1≤N≤M≤500,000,1 \le N \le M \le 500,000,  x,r x, r  不超出 int 数据类型能表示的范围

时间：1.5 sec

空间：256 MB

**本题允许使用STL**

# CST 3-1-3 Feature

---

#### **题目描述**

所谓“线性回归”算法，是对由 nn 个特征 (x1,x2,⋯,xn)(x_1,x_2,\cdots,x_n) 组成的任一样本 xx，输出这些特征的某个“最佳的”线性组合 y=w1x1+w2x2+⋯+wnxny=w_1x_1+w_2x_2+\cdots+w_nx_n，其中 w=(w1,w2,⋯,wn)w=(w_1,w_2,\cdots,w_n) 为权重。我们需要从一组初始权重开始，通过不同的操作修改权重，并计算线性组合的结果。

#### **接口说明**

本题为交互题，我们提供的交互库包括一个头文件 `feature.h` 和一个库文件 `feature_lib.cpp`。前者声明了若干待实现的函数，后者则实现了主函数。在你实现并提交以下函数之后，我们会将库文件和你的程序一起编译、链接：

```
void init(int n, const int *w, const int *x); 
```

特征初始化函数：共有 nn 个特征，编号从 11 到 nn。

ww 和 xx 均是长度为 n+1n+1 的数组，分别存有各特征对应的权重及样本值。

```
void modify_weight(int i, int w); 
```

权重更改函数：将第 ii 个特征的权重修改为 ww。

```
void modify_value(int k, int x); 
```

值更改函数：将权重第 kk 大的特征所对应的样本值修改为 xx。

```
long long calculate(int k); 
```

计算函数：根据权重**绝对值**最大的 kk 个特征（设编号为 i1,i2,⋯,iki_1,i_2,\cdots,i_k），计算输出 y=wi1xi1+wi2xi2+⋯+wikxiky=w_{i_1}x_{i_1}+w_{i_2}x_{i_2}+\cdots+w_{i_k}x_{i_k} 并返回。

这里保证在每次操作的前、后，各特征的**权重绝对值两两不同**。

# CST 3-2-1 Huffman

---

### **描述**

小H想对一篇文章进行编码。文章可以看做一个长为n的全由小写字母构成的字符串，小H想用二进制来分别编码这些小写字母，将英文文本变成一个01字符构成的文本。比如对于文章aaabbb，我用01表示字母a，用10表示字母b，就会变成010101101010。

不同的编码方式会让编码后的结果长度不一样，比如aabbcc，如果用00表示a，01表示b，10表示c，就会变成000001011010。如果用0表示a，用10表示b，用11表示c，则会变成0010101111，长度会更短。

然而，并不是所有编码方案都能够解码。比如aabbcc，如果使用0表示a,1表示b，10表示c的话，编码会得到00111010。可是，当我们遇到了10时，就无法知道对应的是c还是ba了。

因此，我们定义一种合法的编码方式为：任意一个字符对应的编码，不能是另一个字符对应编码的前缀。

现在，小H给了你这篇文章，请你输出任意一种最优编码方式，并输出使用该编码方式后文章的长度。

### **输入**

仅一行，内容为一个长为n的全小写字符串。

### **输出**

第一行一个整数，表示最优编码下的编码后长度。

接下来有若干行，每行开头一个小写字母，接着跟一个空格，再然后跟一个长度不超过100的01字符串（最优情况下编码长度肯定不超过100），表示将该小写字母编码成什么样的01字符串。

我们首先会检查你最优编码长度计算是否正确，接着会检查你的编码方式是否合法，以及使用你的编码方式是否能达到最优编码长度。

对于在原字符串中未出现过的字符，你可以不输出，也可以随便输一个不超过100的01字符串。对于原字符串中出现过的字符，你必须输出他的编码方案。

#### **输入样例 1**

```
aabc
```

#### **输出样例 1**

```
6
a 1
b 00
c 01
```

### **限制**

1 <= n <= 500,000

时间：1 sec

空间：256 MB

### **提示**

Huffman编码

# CST 3-2-2 Temperature

---

### **题目描述**

某气象台每天都要从遍布于各地的观察站采集气温数据，并通过互联网为远程用户提供统计查询服务。其中最常见的一类查询是，用户指定一个矩形区域，查询该区域内的最高气温和最低气温。随着更多观察站的不断建立，原始数据本身的规模急剧膨胀。鉴于传统蛮力算法的效率已无法满足实用要求，气象台只好请你帮忙，通过改进数据结构和算法，提高查询的效率。

借助气象台提供的一组函数接口，服务器端可访问已采集到的所有数据，并报告查询结果。

### **接口说明**

我们提供了一个交互库，包括一个头文件 temperature.h 和一个库文件 temperature_lib.cpp。头文件包含了初始化函数和查询函数的声明，库文件包含了气象台使用这些接口的主函数的实现。

编译时，我们会将库文件和你的程序一起编译和链接，因此**你只需在你的程序中包含头文件，并实现初始化函数和查询函数**。

```
void init(int n, const int *x, const int *y, const int *temp);
```

这是初始化函数。交互库首先会调用这个函数，你可以在此对你的程序进行初始化。

其中 n 表示观察站的总数，x, y, temp 三个数组，分别表示每个观察站的地理坐标 (x[i], y[i]) 以及其所测温度值 temp[i]（0 <= i < n）。

```
void query(int x1, int x2, int y1, int y2, int *tmin, int *tmax);
```

这是查询函数。在初始化完成后，交互库会调用这个函数 m 次，每一次你都需要进行相应地查询并报告结果。

查询的矩形区域的四边分别与 x 或 y 轴平行，(x1, y1) 和 (x2, y2) 描述其一条对角线。恰好位于矩形边界的观察站，也视作落在其中。

# CST 3-2-3 Nearest Neighbor

---

### **题目描述**

给出 nn 个 dd 维实向量 x1,x2,...,xn∈Zd\mathbf{x}_1, \mathbf{x}_2, ..., \mathbf{x}_n \in \mathbb{Z}^d。有若干次询问，每次询问给出 x∈Zd\mathbf{x} \in \mathbb{Z}^d，求给出的 nn 个向量与之欧氏距离的平方的最小值，即求：

min1≤i≤n‖x−xi‖22 \min_{1 \le i \le n} \lVert \mathbf{x} - \mathbf{x}_i \rVert_2^2

### **输入格式**

从标准输入读入数据。

输入第一行为二个整数 d,nd, n，分别表示向量的维数，给出的向量个数。

接下来 nn 行依次描述给出的 nn 个向量，其中第 ii 行为 dd 个整数，表示 xi\mathbf{x}_i 的各个分量。

接下来一行为一个正整数 qq，表示询问的个数。

接下来 qq 行依次描述每个询问，每个询问对应一行 dd 个整数，表示询问的 x\mathbf{x} 的各个分量。

对于所有的输入数据，都有 2≤d≤5,1≤n≤105,1≤q≤2×1052 \le d \le 5, 1 \le n \le 10^{5}, 1 \le q \le 2 \times 10^{5}，所有向量的任意分量的绝对值不超过 10710^{7}。

### **输出格式**

输出到标准输出。

对于每个询问，输出一行一个非负整数，表示所求最小值。

### **样例1输入**

```
2 3
0 0
1 0
1 1
2
0 1
2 -1
```

### **样例1输出**

```
1
2
```

### **样例1解释**

给出的 3 个向量为 x1=(0,0),x2=(1,0),x3=(1,1)\mathbf{x}_1=(0, 0), \mathbf{x}_2=(1, 0), \mathbf{x}_3=(1, 1)。

对于询问 x=(0,1)\mathbf{x}=(0, 1)，与之欧氏距离的平方最小者为 x1\mathbf{x}_1 和 x3\mathbf{x}_3；

对于询问 x=(2,-1)\mathbf{x}=(2, -1)，与之欧氏距离的平方最小者为 x2\mathbf{x}_2。

### **约定与限制**

所有向量的分量数值为在合法范围内均匀随机生成。

时间限制：1.5 s

空间限制：256 MB

**本题允许使用STL**
