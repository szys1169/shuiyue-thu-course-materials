# Sakura IM · 星屿通讯社

一个面向软件工程课程大作业的 PC Web 即时通讯系统，采用柔和的二次元视觉风格。前端使用原生 HTML/CSS/JavaScript，后端使用 Node.js、WebSocket 与 SQLite，启动后可本地演示。

## 快速开始

需要 Node.js 22.5 或更新版本。

```bash
npm install
npm start
```

浏览器打开 <http://localhost:3000>。首次启动会自动创建 `data/sakura.sqlite` 并写入体验数据。

## 功能

- 邮箱注册、登录、个人昵称/头像/签名维护、退出登录；密码通过 scrypt 加盐哈希保存。
- 用户注销和关联个人资料清理；若注销用户是群主，会把群主身份移交给现存群成员。
- 用户搜索、好友申请、申请通过、好友列表和好友删除。
- 私聊与群聊、会话列表和搜索、群聊邀请箱、成员邀请/移除/退出、群公告。
- 消息实时 WebSocket 推送、历史分页读取、已读游标、撤回和仅对自己删除。
- SQLite 关系数据持久化、外键约束与消息查询索引。
- 适配窄屏浏览器的响应式布局、二次元头像和樱花/星空视觉主题。

## 项目结构

```text
server.js                 HTTP API、认证、SQLite、WebSocket
public/index.html         页面结构
public/styles.css         视觉系统与响应式样式
public/app.js             登录态、聊天交互与实时事件
docs/                     需求追踪、数据库/API、演示与过程文档
data/                     本地 SQLite 数据（运行后生成，不提交）
```

## 本机数据重置

停止服务后，删除 `data/sakura.sqlite` 及对应的 `-shm`、`-wal` 文件；下次启动会重新建立体验数据。请勿将含个人聊天内容的数据库提交到 Git。

## 部署提示

服务默认监听 `0.0.0.0` 对应端口 3000。生产环境使用 HTTPS 反向代理并设置强随机 `JWT_SECRET`、持久化 `data/` 目录、备份 SQLite 数据库，并基于真实课程环境建立 CI、后端单元测试和覆盖率门槛。当前仓库尚未配置课程组 Git 远程、CI/CD 密钥或正式部署地址。
