# CST 2-3-2 Sect

---

### 问题描述

在一个古老的门派中，所有门人（人数记为 NN）按照师承关系形成了一个严格的等级制度，它可以用一棵有根树来表示。 门派中的所有人均可看作树上的一个节点，用从 1 到 NN 的编号表示，每个人编号各不相同。树上每一条边代表师徒的传承关系（也即父节点和子节点为师父-弟子关系）。特别地，这棵树的根节点（编号记为 1）便是门派的开山祖师。

每个人的实力可以用“内力值”来衡量，编号为 ii 的人内力值记为 aia_i，所有人的内力值互不相同。

门派有一个古老的传统：所有人都要寻找自己的“引路者”，也即在师承路径上从前到后寻找第一个内力值比自己高的前辈。

师承路径遵循如下的规则：

- 开山祖师的师承路径为空（L1=[]L_1 = []）
- 若某人师父的编号为 uu, 师承路径为 LuL_u, 则此人的师承路径有如下可能：   若师父只有他一名弟子，则他的师承路径为 [u]+Lu [u] + L_u ，其中加法为列表的拼接（例如 [3]+[6,5]=[3,6,5][3] + [6, 5] = [3, 6, 5]）。   若师父门下有多名弟子，则需要判断他是否为“正统弟子”。“正统弟子”的判断方法为，比较各个弟子派系的所有门人（也即以该弟子为根的子树的所有节点）内力值之和，内力值之和最高的弟子即为正统弟子。若有多个弟子的门人内力值之和最高，则编号最小的弟子为“正统弟子”。 若此人为“正统弟子”，则其师承路径为 [u]+Lu [u] + L_u ；否则他将无法向上查找，也即师承路径为空。

现在希望你求出门派中每一个门人的引路者。

### 输入格式

第一行包含一个整数 NN，表示门派门人总数。

随后 NN 行，以孩子节点表示法给出门派的师承关系树。 具体来说，第 ii 行对应于第 ii 个节点（1≤i≤N1 \le i \le N）：首先是一个非负整数 did_i，即该节点弟子的数目；随后是 did_i 个正整数，逐一列出弟子节点的编号。

接下来一行，包含 NN 个整数，给出所有门人的内力值，第 ii 个整数为 aia_i。所有内力值互不相同。

### 输出格式

输出 NN 行，第 ii 行输出编号为 ii 的门人的引路者编号。如果找不到这样的引路者，则输出 -1。

### 输入样例

```
7
3 2 3 4
2 5 6
1 7
0
0
0
0
89 7 10 4 5 6 103
```

### 输出样例

```
-1
-1
1
-1
-1
2
-1
```

### 样例解释

该样例对应着下面这一棵多叉树：

```
    1
   /|\
  2 3 4
 /| |
5 6 7
```

各个节点的师承路径如下

- 1: []
- 2: []
- 3: [1]
- 4: []
- 5: []
- 6: [2]
- 7: [3, 1]

对于节点 2, 其正统弟子为 6。 对于节点 1, 其正统弟子为 3。

### 数据范围

- 1≤N≤1061 \le N \le 10^6
- ai∈[1,109]a_i \in [1, 10^9]，且互不相同
- 有 20% 的数据为链 (所有节点至多有一个弟子)

时间限制：1 秒  
 空间限制：256 MB  
 **本题不限制栈空间大小**
