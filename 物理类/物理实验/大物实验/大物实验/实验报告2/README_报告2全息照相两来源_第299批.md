# 全息照相两份来源的新位置

两份共12页的全息照相资料已按原名原字节分组移入私有学习目录。9页件为有身份的手写报告，3页件从实验思考题起，含误差分析和个人总结，前文及完整性未核；不称完整报告或官方空白题纸。

身份、评价、私人经历日期不转录；全部黑边透印、批改和页序保持，不补前文或修订答案。未署名片段也不当净稿，报告2其它33原件仍在原位。
