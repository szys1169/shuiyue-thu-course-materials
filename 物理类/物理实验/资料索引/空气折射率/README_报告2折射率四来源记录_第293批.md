# 报告2中的空气折射率四来源记录

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本次补入另一拼写题名的9页手写报告，含自制封面、原理仪器步骤、数据与不确定度、误差思考、私人总结及末页原始记录。

封面有实际个人身份，原文、评价、私人日期和经历只在私有学习目录保存，不在说明中转录。原文件名不同拼写、字节、页序、纸面批改和黑边透印全部保持，不裁剪、删页或修订答案，也不认来源序号代表新版或私人日期代表授课学期。

四个折射率来源原路径均已有可恢复去向，共7,181,632字节、26文件页、4个不同哈希。证据为上一批3份与本批1份，本地四份哈希重新核对；历史三份复核已保存的云盘字节，并非四份本次全部重新下载。不称四个独立报告或版次，只有上一批打印5页件标明物理A(2)，不推广到本件及其它稿件。报告2其余39份原件（含仪器调整两份）不在本组范围内。
