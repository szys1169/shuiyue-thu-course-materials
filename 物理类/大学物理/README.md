- 主要来源：[自有物理资料库·大学物理](https://cloud.tsinghua.edu.cn/library/6f4b1cfc-208b-4b3f-b2ac-bac77f97246f/%E7%89%A9%E7%90%86/%E7%89%A9%E7%90%86%E7%B1%BB/%E5%A4%A7%E5%AD%A6%E7%89%A9%E7%90%86)原1、2、大物B、戴松涛、教材、李桂琴、王佳平、张卫华、周树云目录，以及本地保存的B2期中扫描资料。逐批保留来源、原文件名和原件字节。
- 旧1/2只是历史目录名，不据此认定课程学期；相同SHA256的来源副本保留来源关系，可恢复旧副本归入过程材料，不作为新题重复列出。
- “教师来源”说明原目录来源，不自动认证每份文件的作者；图像题、匿名笔记、学生回忆、课堂讲题照片和参考答案均保留角色说明。
- 第三版与第四版教材不自动互配题号。第四版位置标注PDF只标出错误位置，具体修正见勘误表，不能当作正文已修正后的新版本。
- 网络学堂已核查的大学物理1、大学物理2课程文件区未见附件；另平台入口仅作来源记录，不据此声称已下载全部课程资料，也不把未来作业或提交状态补造出来。
- 原大物B试题组中的工程光学回忆、物理光学题与参考答案，已按正文移到同库物理类/光学；A样题归复习/样卷，明确的中国矿业大学试卷归参考试题/外校。
- 2008文字回忆稿含传播提示，仅保留原有云盘和本地副本；GitHub当前目录只保留来源元信息，不公开正文。
- 当前可学习资料均以原文件或展开后的必要配套文件管理；原始压缩附件、上传差异版本、迁空目录和旧入口保留在`_过程材料`中。
