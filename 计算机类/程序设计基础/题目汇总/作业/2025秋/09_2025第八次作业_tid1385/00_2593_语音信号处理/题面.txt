语音信号处理
时间限制： ms
内存限制： MB

题目描述
给定一个 WAV 文件 格式的语音数据，需要根据语音文件的 数据长度 mod 6 来自动执行一种特定的处理功能。每个处理功能按照文件的样本数据长度（即采样点数的 mod 6 值）进行选择，功能具体如下：len % 6功能名称说明0剪切剪切区间：删除[1000, 3000] 的采样（含两端），其余前后拼接1中心削波上阈值 = 800，下阈值 = –800，将位于该阈值范围间的值全部删除2强制静音将区间 [2000, 4000] 的采样全部置为 03片段求逆将区间 [500, 2500] 的采样进行逆序，其余保持不变4截顶处理上截顶 = 1000，下截顶 = –1000，超出部分截到阈值5加噪声为全段音频添加从 1000 开始的锯齿波，即从1000开始反复递减至0再递增回1000，数列示意如下：1000, 999, 998, ..., 0, 1, 2, ..., 999, 1000, 999, ...语音数据下标从0开始，所有区间均为闭区间。所有操作都按固定的采样区间和规则进行。请根据输入的 WAV 文件，读取其数据，并根据文件的采样长度执行相应操作。

输入描述
输入是一个 WAV 文件（input.wav），文件中包含 PCM 编码的音频数据（单声道）。需要根据该文件的采样点总数 N 来判断使用哪种操作。

输出描述
输出是一个处理后的 WAV 文件（output.wav），该文件也是 PCM 编码格式。

样例输入
假设我们给定的 WAV 文件数据包含以下整数值（仅为示意，实际文件中是 PCM 编码的音频数据）：

文件：input.wav
采样数据： [1000, 1200, 1500, 800, -600, 700, 300, 100, 0, 50]

样例输出
假设在处理后，生成了一个新的 WAV 文件 output.wav。

文件：output.wav
处理后的数据： [1000, 1000, 1000, 800, -600, 700, 300, 100, 0, 50]

注释
len % 6 = 4 触发的是 截顶处理，则所有大于1000的数据将被截断至1000，小于-1000的数据将被截断至-1000。wav文件格式可参照课程ppt L07-数据组织与处理（下）-V9 92-102页内容。为保证生成的wav可读性，请注意文件头中的数据大小也需要修改。文件头中size均以字节为单位，由于测试音频统一选用单声道16位编码，可默认采样点数量 = data_size / 2。以下是一个典型的文件头结构：struct WAVHeader {
    char riff[4];        // "RIFF"
    uint32_t size;       // file size - 8
    char wave[4];        // "WAVE"
    char fmt[4];         // "fmt "
    uint32_t fmt_size;   // 16
    uint16_t audio_fmt;  // 1 (PCM)
    uint16_t channels;   // 1
    uint32_t sample_rate;
    uint32_t byte_rate;
    uint16_t block_align;
    uint16_t bits_per_sample; // 16
    char data[4];        // "data"
    uint32_t data_size;  // following data bytes
};其中的uint32_t为4字节无符号整型，uint16_t为仅占用2字节的无符号整型，size单位均为字节，需要修改的项包括size及data_size，分别含义为去除riff、size外的块（riff块）的大小，及采样数据（data块）占据的大小。riff块计算方式：hdr.size = 4 + (8 + hdr.fmt_size) + (8 + hdr.data_size)hdr.data_size = 2 * num_samples注意：本题较难，请尽早开始，有问题及时平台或微信询问。
