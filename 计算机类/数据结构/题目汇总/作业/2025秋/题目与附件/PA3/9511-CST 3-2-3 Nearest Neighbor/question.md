# CST 3-2-3 Nearest Neighbor

---

### **题目描述**

给出 nn 个 dd 维实向量 x1,x2,...,xn∈Zd\mathbf{x}_1, \mathbf{x}_2, ..., \mathbf{x}_n \in \mathbb{Z}^d。有若干次询问，每次询问给出 x∈Zd\mathbf{x} \in \mathbb{Z}^d，求给出的 nn 个向量与之欧氏距离的平方的最小值，即求：

min1≤i≤n‖x−xi‖22 \min_{1 \le i \le n} \lVert \mathbf{x} - \mathbf{x}_i \rVert_2^2

### **输入格式**

从标准输入读入数据。

输入第一行为二个整数 d,nd, n，分别表示向量的维数，给出的向量个数。

接下来 nn 行依次描述给出的 nn 个向量，其中第 ii 行为 dd 个整数，表示 xi\mathbf{x}_i 的各个分量。

接下来一行为一个正整数 qq，表示询问的个数。

接下来 qq 行依次描述每个询问，每个询问对应一行 dd 个整数，表示询问的 x\mathbf{x} 的各个分量。

对于所有的输入数据，都有 2≤d≤5,1≤n≤105,1≤q≤2×1052 \le d \le 5, 1 \le n \le 10^{5}, 1 \le q \le 2 \times 10^{5}，所有向量的任意分量的绝对值不超过 10710^{7}。

### **输出格式**

输出到标准输出。

对于每个询问，输出一行一个非负整数，表示所求最小值。

### **样例1输入**

```
2 3
0 0
1 0
1 1
2
0 1
2 -1
```

### **样例1输出**

```
1
2
```

### **样例1解释**

给出的 3 个向量为 x1=(0,0),x2=(1,0),x3=(1,1)\mathbf{x}_1=(0, 0), \mathbf{x}_2=(1, 0), \mathbf{x}_3=(1, 1)。

对于询问 x=(0,1)\mathbf{x}=(0, 1)，与之欧氏距离的平方最小者为 x1\mathbf{x}_1 和 x3\mathbf{x}_3；

对于询问 x=(2,-1)\mathbf{x}=(2, -1)，与之欧氏距离的平方最小者为 x2\mathbf{x}_2。

### **约定与限制**

所有向量的分量数值为在合法范围内均匀随机生成。

时间限制：1.5 s

空间限制：256 MB

**本题允许使用STL**

### **提示**

- KD 树
- 使用 KD 树时，可以在叶子上保存多于单个点以提升效率
