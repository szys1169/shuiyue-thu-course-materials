# CST 4-1-1 Split String

---

#### **描述**

字符串匹配问题，可以细分为两种类型：可重叠匹配，以及无重叠匹配。以文本串T="ababa"和模式串P="aba"为例，如果可重叠，便有两处匹配（T中作为前缀、后缀的“aba”）；反之若无重叠，则只有一处匹配（前缀、后缀“aba”只能取其中之一）。 若将任意串P在串T中无重叠匹配的数目记作g(T,P)g(T,P)，则不难验证：串T无论如何**拆分**为非空的前缀T1与后缀T2，都必有： g(T1,P)+g(T2,P)≤g(T,P) g(T1, P) + g(T2, P) \leq g(T, P)  我们在这里关注的是，有多少种拆分能使上式取等号。

#### **输入**

总共两行，分别给出文本串T、模式串P。

#### **输出**

只有一个整数，即无重叠匹配总数保持不变的**拆分**方式的总数。

#### **输入样例1**

```
ababa
aba
```

#### **输出样例1**

```
4
```

#### **输入样例2**

```
ababa
bab
```

#### **输出样例2**

```
2
```

#### **限制**

1≤|P|≤|T|≤1,000,0001 \leq |P| \leq |T| \leq 1,000,000

字符串均由小写英文字母构成

时间限制：1 sec

空间限制：256 MB
