# 项目说明与需求追踪

## 项目目标

构建一个可在 PC 浏览器使用的即时通讯系统，为两个或多个在线用户提供好友、私聊、群聊、消息同步和历史查看能力。界面采用二次元轻幻想风格：樱花粉、雾紫和夜空蓝配色，星岛意象、圆角会话卡片和轻量动效。

## 角色

- **访客**：注册账号或使用体验账号登录。
- **普通用户**：维护个人名片、搜索用户、申请好友、收发私聊和群聊消息、创建群聊、处理群聊邀请。
- **群主/管理员**：编辑群公告、邀请成员；群主可移除普通成员。

## 非功能设计

- **安全性**：密码使用随机盐和 scrypt 哈希；API 通过短期外令牌认证；SQL 使用参数化语句；按会话成员校验历史和消息操作权限。
- **完整性**：外键、唯一约束、群成员主键、SQLite WAL；消息、发送人和会话通过关系表引用。
- **可用性**：单命令启动、内置体验数据、API 健康检查、WebSocket 重连。
- **界面可用性**：中文提示、空状态、错误 toast、桌面优先布局和窄屏适配。
- **隐私**：服务端不提供任意用户浏览其他会话的接口；个人删除通过用户 ID 列表隔离。

## 当前边界与后续扩展

首版不包含文件/图片上传、手机号码验证、管理员授权界面、端到端加密、多实例消息代理、在线用户持久状态和部署域名。消息使用服务端 SQLite 持久化；WebSocket 在线推送失效时，客户端需打开会话或刷新后通过历史接口恢复。上线前还需配置 TLS、强密钥、请求限流、备份和 CI 覆盖率门槛。
