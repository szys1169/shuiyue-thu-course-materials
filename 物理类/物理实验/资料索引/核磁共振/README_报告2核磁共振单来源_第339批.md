# 核磁共振与混合附页来源

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本份PDF为41,666,079字节、15文件页。前9页为核磁共振测磁场填写稿，其中6–8页兼有霍尔效应与电导率处理；后6页为逸出功拟合图表及计算附页。整件保留，不将它认作三份独立报告或完整配套。

原件连同批注、照片顶边、阴影、页边和附页完整云盘保存，本批未新增入Git。第5页签署样与日期标记的归属未核，具体值不在说明中转录，原题名保持，作者、学期待核。

本组仅整理这一条来源路径，报告2另4份原件保持原位。
