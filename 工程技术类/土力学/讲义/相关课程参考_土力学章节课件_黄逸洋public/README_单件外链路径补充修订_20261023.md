# 土坡稳定课件单件外链修订

本组资料来源于黄逸洋公开共享云盘的土力学相关目录，既有来源说明和清单继续作为来源历史记录保留。

`PPTX/第7章 土坡稳定分析_去个人机器路径整理副本.pptx` 对应来源同章课件。仅把第 18 页的一条外部视频链接从个人电脑绝对目录改为原视频文件名的相对链接，保留该关系的 Id、Type、TargetMode 及原 `.flv` 文件名。

全部 83 页的幻灯片 XML、文字、图片、媒体、版式、备注和嵌入对象均保持字节一致，ZIP 中仅一个关系文件的一个 Target 属性改变，其余 596 个 part 逐字节 SHA 一致。未重绘课件，未运行 PowerPoint，也不声称全部幻灯片视觉检查。

来源没有提供这个外链视频，整理副本不补齐视频，也不保证播放功能可用。原件完整保留于课程过程目录，未覆盖。当前整理以本说明和补充清单为准，旧清单所列原件不列入本轮公开同步白名单。本说明不作为云端上传完成回执。
