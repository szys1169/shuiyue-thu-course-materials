# 瞬态信号七条原题名来源路径

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本批末一份为13页彩色照片填写稿，含传输线与超声原理、波形数据、数据处理分析及两页原始记录附纸。

原件连同批注、划改数据、照片阴影和页边完整云盘保存，本批未新增Git。身份、私人日期和评价不在说明中转录，编号沿原题名，作者、学期待核。

七条原题名路径共91,749,495字节、83文件页、7个不同SHA，均有去向记录。其中一份从仪器介绍起页，没有独立封面，身份及前文完整性待核；因此此账不代表七份独立完整报告或新版。前六件沿用第321、323、325批已验来源及保存云盘字节，本批新回取末一件，本地七件重新核对哈希。报告2另11份原件保持原位。
