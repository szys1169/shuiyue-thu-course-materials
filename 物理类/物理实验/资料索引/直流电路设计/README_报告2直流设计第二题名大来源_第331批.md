# 直流设计第二原题名来源

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本份PDF为35,031,491字节、14文件页，含填写封面、原理仪器步骤、数据处理、思考题、个人总结和两页原始记录。

原件连同批注、页顶使用限制、照片阴影、页边和附页完整云盘保存，本批未新增入Git。身份、私人日期及评价不在说明中转录，编号沿原题名，作者、学期待核。

本组仅整理这一条来源路径，另一份较大直流设计来源仍在原位。报告2另8份原件保持原位。
