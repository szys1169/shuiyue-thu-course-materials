## 题目描述

在一片幽深的森林中，冰人和火人误入了一座充满机关的遗迹迷宫。迷宫里有厚重的石门和散落在各处的机关按钮。只有合理地踩住开关、穿过石门，两人才能一起走到终点并逃出密林。迷宫说明迷宫是一个 R × C 的字符网格，每个格子含义如下：#：墙，不能进入；.：空地，可以自由进入；F：火人的起始位置（视作可站立的空地）；I：冰人的起始位置（视作可站立的空地）；X：终点（目标格，可以进入并停留）；A–C：石门格，每个大写字母代表一扇门（例如门 A、门 B 等），每扇门至多出现 1 次；a–c：开关格，与同字母的大写门对应（例如 a 控制门 A，b 控制门 B 等），开关可以出现在地图上的多个位置。补充说明：同一个门可能有多个开关格（同一小写字母可以在多处出现）；除 # 之外的所有格子（包括门格与开关格）都可以被进入和停留；允许两个人站在同一个格子上（包括空地、开关、终点）。移动与状态为方便描述，我们采用离散时间的状态表示。起始状态（第 0 步）记为 S0：火人在字符 F 位置，冰人在字符 I 位置。每执行一步动作，从状态 Sn（第 n 步的状态）变为状态 Sn+1。在一步状态转移 Sn → Sn+1 中：火人可以选择向上、下、左、右移动一格，或保持原地不动；冰人也可以独立地选择向上、下、左、右移动一格，或保持原地不动；两人的动作同时发生。移动需要满足：任何人都不能走出地图边界，也不能进入格子 #；允许两人移动到同一个格子（包括空地、开关和终点）；如果某一步中任意一人的移动违反上述规则或下面的石门开关规则，则该步视为非法，不可执行。石门与开关规则出于安全考虑，对任意一扇石门 D（A–C）及其对应的开关 d（a–c），有以下两条规则：门通行规则：在某一步 Sn → Sn+1 中，若某人的移动起点或终点是门格 D，则这一步必须满足：在状态 Sn 中，至少有一人站在门 D 的任意一个开关格 d 上；在状态 Sn+1 中，至少也有一人站在门 D 的任意一个开关格 d 上。也就是说，只要某人在这一小步中“进入”或“离开”或是“停留”在门 D，则在移动前后两个状态中都必须有人（可以为另一个人，也可以为自己）踩在对应开关上，否则非法。开关保护规则：在某个状态 Sn 中，若一人站在门格 D 上，另一人站在对应开关格 d 上，则在下一步移动 Sn → Sn+1 中：站在开关格 d 上的人必须保持原地不动（即这个人在 Sn 和 Sn+1 中的位置不变）。最终目标请寻找最快的移动方式，使得冰人和火人能从初始状态 S0 出发，按照合法规则进行移动 S0 → S1 → S2 → … → ST ，并在最终状态 ST 中：冰人和火人都站在终点格 X 上。如果存在这样的移动方式，则输出这个最小步数 T。如果不存在任何合法方式使得两人均到达终点，则输出 -1。
