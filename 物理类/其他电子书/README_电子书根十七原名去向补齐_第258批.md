本轮17份现有本地原件重新计算SHA，均与既有记录一致。第107批4份规范原件当前云盘回取后逐SHA一致；另外13份正文沿原批历史云盘验收，本轮未全部重新下载。原根7份历史安全说明本轮回取，ZIP CRC、精确文件集及字节SHA与本地/旧基线一致。此处是来源路径去向核对，不是全书完整、全部公式正确或全页隐私审净证明。

21个来源子目录的182条原名路径另见第256批导航；加本根17条，共199条历史来源路径，198条有去向、1条仍未处理。它们不是199部独立书或课程；本批不处理剩余原件，不替换第128、160、256批入口。
