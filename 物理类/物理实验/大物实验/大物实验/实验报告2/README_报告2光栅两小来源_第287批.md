# 光栅两份来源的新位置

两份共17页的光栅衍射手写报告已保留原名原字节归入私有学习目录，含数据、问答、原始记录与纸面批改。私人身份、评价和日期不在说明中转录；划去的数据页和全部附页仍保持，不裁剪或修订答案。

只整理本次两份小来源，来源编号不证明版次先后，也不证明独立报告或授课学期。另45份原件（包括较大的光栅来源）保持原位。
