# 报告2中的光栅衍射两份来源

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人原有副本，保留两份不同字节的手写实验报告，共4,541,343字节、17文件页。

6页件含自制封面、原理仪器、操作和处理思路及末页手写原始记录；11页件含原理步骤、数据计算、课前问答、思考题与误差分析，其中划去的数据页仍完整保留。两份均有私人身份及纸面批改，原文、评价和私人日期只在私有学习目录保存，不在说明中转录。

原文件名、字节、页序、黑边透印和全部记录保持，不裁剪、删页、修订答案，也不认定来源编号代表版次先后或日期代表授课学期。报告2另45份原件（包括另一份较大光栅资料）仍在原位，不在本组范围内。
