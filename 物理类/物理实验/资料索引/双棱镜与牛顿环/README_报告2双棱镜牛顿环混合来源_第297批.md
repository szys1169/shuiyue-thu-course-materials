# 报告2中的双棱镜与牛顿环混合来源

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。原题名虽写双棱镜，正文两份均混合双棱镜和牛顿环测曲率半径内容，共6,813,639字节、29文件页、2个不同哈希，按实际内容分组保留。

13页件的首两页是同封面的彩色和灰度扫描，后含双棱镜、牛顿环、数据处理及私人总结；16页件含两实验原理、步骤、记录和思考，末页另附偏振光学原始记录纸。该附页只按已见角色说明，不推定与前文同一作者或已经证实配套。全部PDF保持整件，不拆页，不把混合稿完整标为单一双棱镜报告。
