# CST 4-1-2 Pattern Matching

---

### **题目描述**

给定一个 MM 行 NN 列的二维字符矩阵 TT 和 kk 个 mm 行 nn 列的目标矩阵 Pi (1≤i≤k)P_i\ (1 \le i \le k)，求在 TT 中每个 PiP_i 出现的次数 tit_i：

### **输入格式**

输入第一行为五个整数 M,N,m,n,kM, N, m, n, k。

接下来的 MM 行依次给出矩阵 TT 的各行元素，每行有一个长为 NN 的字符串，表示 TT 的各个元素。

接下来 kk 部分，每部分有 mm 行。其中第 ii 部分的 mm 行依次给出目标矩阵 PiP_i 的各行元素，每行有一个长为 nn 的字符串，表示 PiP_i 的各个元素。

### **输出格式**

输出共 kk 行，在第 ii 行有一个整数 tit_i，表示所求的出现次数。

### **样例1输入**

```
4 4 2 2 2
abab
efcd
abcd
efcd
ab
ef
cd
cd
```

### **样例1输出**

```
2
2
```

### **约定与限制**

对前 30% 的数据，满足 1≤M≤50,1≤N≤50,1≤m≤2,1≤n≤2,1≤k≤11 \le M \le 50, 1 \le N \le 50, 1 \le m \le 2, 1 \le n \le 2, 1 \le k \le 1。

对前 50% 的数据，满足 1≤M≤200,1≤N≤200,1≤m≤6,1≤n≤6,1≤k≤101 \le M \le 200, 1 \le N \le 200, 1 \le m \le 6, 1 \le n \le 6, 1 \le k \le 10。

对前 80% 的数据，满足 1≤M≤2000,1≤N≤1000,1≤m≤10,1≤n≤10,1≤k≤1001 \le M \le 2000, 1 \le N \le 1000, 1 \le m \le 10, 1 \le n \le 10, 1 \le k \le 100。

对前 100% 的数据，满足 1≤M≤2000,1≤N≤1000,1≤m≤100,1≤n≤100,1≤k≤5001 \le M \le 2000, 1 \le N \le 1000, 1 \le m \le 100, 1 \le n \le 100, 1 \le k \le 500。

所有矩阵元素均为大小写字母。

- 时间限制：1.5s
- 空间限制：256MB

**本题允许使用STL**
