# 有限差分补充源码与实验计算文本

来源：[黄逸洋public传热学](https://cloud.tsinghua.edu.cn/d/cc494ee97f884a3b9ffb/?p=%2F2.6_%E8%83%BD%E6%BA%90%E5%8A%A8%E5%8A%9B%E7%B1%BB_%E4%BC%A0%E7%83%AD%E5%AD%A6&mode=list)原数值作业及实验资料目录。

保存2份C有限差分源码、2份同名而异字节的数值输出文本，以及数据.txt、matlab计算式.txt和一份来源已有的按页提取热源法实验指导文本。两输出各10000个非空数值对行，分来源1/2保留原名，不推断对应哪个版本代码。

源码与实验文本分别分组，原编码、原字节和公式保持；不执行源码、不重算结果，也没有重新OCR或修复文字。来源原上级目录的私人标识仅保过程映射，公版以源键和SHA定位。含编号的另两份C未纳入本组。
