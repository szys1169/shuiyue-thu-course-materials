## 题目描述

在草莓巧克力（StrawChoco）王国，生活着mmm只草莓（Strawberry）和nnn只巧克力（Chocolate），每只草莓巧克力都有自己的心情值moodmoodmood，一开始所有草莓巧克力的心情值都是000。

草莓巧克力们经常会一起进行活动，具体来说有三种活动：

- 一只草莓巧克力和另一只草莓巧克力去逛动物园。
- 一只草莓巧克力和另一只草莓巧克力去逛商场。
- 一只草莓巧克力过生日，并且邀请其他草莓巧克力来参加生日活动，草莓和巧克力的邀请策略有所区别：1. 巧克力仅会邀请最后一只一起去逛动物园的草莓巧克力来参加，如果这只巧克力之前从未逛过动物园，则不会邀请任何草莓巧克力。
2. 草莓会邀请所有曾一起逛商场的草莓巧克力来参加。

作为草莓巧克力王国的国王，你需要记录下每只草莓巧克力的心情值，这个值会在草莓巧克力参加活动的时候变化

**对于巧克力：**

- 巧克力喜欢动物园，因为能看到熊猫，巧克力逛动物园时心情值增加555。
- 巧克力逛商场时心情值增加111。
- 巧克力过生日时心情值增加111，如果这只巧克力邀请了其他草莓巧克力，则心情值再增加555。
- 巧克力被其他草莓巧克力邀请参加生日时心情值增加111。

**对于草莓：**

- 草莓逛动物园时心情值增加111。
- 草莓逛商场时心情值增加555。
- 草莓过生日时，假设邀请了kkk只草莓巧克力来参加，则心情值增加kkk。
- 草莓被其他草莓巧克力邀请参加生日时心情值增加111。
- 特别地：当和草莓一起逛动物园/商场的是巧克力时，心情值额外增加555。

活动相关的接口已经在`event.h`中实现，请你在`strawchoco.h`和`strawchoco.cpp`中实现`Strawberry`类和`Chocolate`类，正确维护心情值。

题目文件下载：[downloads.zip](_downloads/downloads_%E5%B1%95%E5%BC%80/README.md)

## 输入格式

第一行三个整数n,m,ln,m,ln,m,l，分别表示巧克力数量，草莓数量，发生的活动数量。

所有草莓巧克力按照000到n+m−1n+m-1n+m−1编号，其中000到n−1n-1n−1为巧克力，剩余为草莓。

接下来lll行，每行首先有一个整数opopop

- op=0op=0op=0，后接两个整数x,yx,yx,y，表示编号为xxx和编号为yyy的草莓巧克力一起逛动物园。
- op=1op=1op=1，后接两个整数x,yx,yx,y，表示编号为xxx和编号为yyy的草莓巧克力一起逛商场。
- op=2op=2op=2，后接一个整数xxx，表示编号为xxx的草莓巧克力过生日。

所有活动按照输入顺序发生。

## 输出格式

输出n+mn+mn+m行，第iii一个整数表示全部活动结束后编号为i−1i-1i−1的草莓巧克力的心情值。

## 样例输入

```
2 2 7
0 0 1
1 0 2
0 1 3
2 0
1 2 3
1 2 0
2 2
```

## 样例输出

```
14
11
27
12
```

样例输出解释：

编号为0的巧克力，逛了1次动物园，2次商场，过了一次生日，且生日时邀请了编号为1的巧克力，又在编号为2的草莓生日时被邀请，合计心情值为14。

编号为1的巧克力，逛了2次动物园，在编号为0的巧克力生日时被邀请，合计心情值为11。

编号为2的草莓，逛了3次商场，其中两次是和编号为0的巧克力一起的，过了一次生日，邀请了编号为0和3的草莓巧克力，合计心情值为27。

编号为3的草莓，逛了1次动物园，和编号为1的巧克力一起，逛了一次商场，然后在编号为2的草莓生日时被邀请，合计心情值为12。

## 测试数据及约定

本题共10个测试点，每个测试点10分。

各个测试点约束如下：

- 测试点0、1、2、3：只包含巧克力，不存在过生日活动。
- 测试点4、5、6：不存在过生日活动。
- 测试点7、8、9：无特殊约束。

对于所有测试点：n,m,l≤1000n,m,l \le 1000n,m,l≤1000
