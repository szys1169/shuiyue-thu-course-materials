# 复习材料来源与身份

全部来自[个人云盘源库](https://cloud.tsinghua.edu.cn/library/4ab0b621-2cd7-4d5d-bb13-1f9e20bb7f54/%E5%A4%8D%E5%88%86%E6%9E%90/)根目录：二轮复习三份、期末复习一份、期中复习两份。

两份期中复习SHA256不同。原作者留有空TXT，其文件名说明“（1）是我的复习文档，之前上传错了，另外一个是why的”。因此保留原名，将 `(1)` 文件标识为原库所有者的个人复习文档，另一个仅沿用“why”这一来源标记，不补全身份。这是作者区别，不按重复文件删除或覆盖。原说明文件存于 `../_过程材料/原说明/`。

其他材料作者和年份未在可核查来源中确认，按原题名保留，不统一冒称教师讲义。
