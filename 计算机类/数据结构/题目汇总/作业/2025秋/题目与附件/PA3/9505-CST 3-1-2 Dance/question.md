# CST 3-1-2 Dance

---

### **题目描述**

在苏格兰舞会上，人们会**围圈**跳舞，并由主持人带领进行着队形变换。舞会期间，不断会有新人加入。主持人确定所有变换之后，希望预先知道，一曲终了时的队形将会如何。

人们在舞圈里的位置，自正门处起**顺时针地**从 00 开始逐个编号。从最初空的舞圈开始，反复做下列四种队形变换：

- IxpI\, x\, p：代号为整数 xx 的舞者，加入到舞圈中 p−1p-1 号与 pp 号舞者之间，编号取作 pp，原 pp 至 n−1n-1 号舞者的编号各自加一，其中 0≤p≤n0 \le p \le n，nn为当前的舞者总数。特别地，如果 p=np = n，则 xx 将插到 n−1n-1 号与 00 号之间，编号取作 nn，原先舞者的编号均保持不变；如果 p=0p=0，则 xx 将插到 00 号与 n−1n-1 号之间，编号取作 00，原先的所有舞者编号各自加一；
- SijS\, i\, j：ii 号舞者与 jj 号交换位置。0≤i,j<n0 \le i,j < n；
- RrR\, r：舞圈整体**顺时针**旋转 rr 人，r∈Zr \in \mathbb{Z}，舞者的编号（在模 nn 意义下）各自**增加** rr 个单位。当然，若 r<0r<0，则相当于是**逆时针**旋转，所有编号减少 −r-r 个单位；
- FijF\, i\, j：ii 至 jj 号舞者整体区间翻转，0≤i,j<n0 \le i,j <n。这里的区间是就循环意义而言的，以 n=7n = 7 为例，若舞者代号依次为 a,b,c,d,e,f,ga,b,c,d,e,f,g，则在做过 F14F\, 1\, 4 翻转后，代号序列将转成 a,e,d,c,b_,f,ga,\underline{e,d,c,b},f,g；而在做过 F41F\, 4\, 1 翻转后，代号序列将转成 f,e_,c,d,b,a,g_\underline{f,e},c,d,\underline{b,a,g}。

### **输入格式**

第一行有两个正整数：NN 为最终的舞者总数，MM 为队形变换的总次数。 接下来的 MM 行，按照上述格式逐一列出各次变换。S,R,FS,R,F 操作保证当时的舞圈不空，i,ji,j 总是当前舞圈中的合法位置。

### **输出格式**

仅一行，按最终次序逐个列出舞者代号。

### **输入样例**

```
5 20
I 4399 0
I 1024 1
R -1
S 0 1
I 7777 1
R 20
S 1 2
F 2 0
F 0 1
F 1 0
I 1111 0
I 2048 4
S 1 3
R -3
F 0 2
F 3 0
S 0 0
S 1 4
F 3 2
R 2
```

### **输出样例**

```
1024 4399 7777 2048 1111
```

### **限制**

1≤N≤M≤500,000,1 \le N \le M \le 500,000,  x,r x, r  不超出 int 数据类型能表示的范围

时间：1.5 sec

空间：256 MB

**本题允许使用STL**

### **提示**

第2，3点提示对复杂度没有实质性的影响，不必须按这两点思路解题。

- 伸展树(splay)
- 思考如何在 O(1) 时间内完成 R 操作
- 思考如何避免对树的 split/merge 操作
- 请注意 `scanf("%c", &t)` 和 `scanf(" %c", &t)` 的区别之处
