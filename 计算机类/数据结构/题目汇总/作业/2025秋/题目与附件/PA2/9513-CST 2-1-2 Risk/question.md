# CST 2-1-2 Risk

---

#### **描述**

从公元33世纪到3333世纪 ，月球城一直处于新型呼吸道疾病DIVOC-33疫情期间，每一天都是低风险、中风险、高风险三种状态之一。

DIVOC-33是一种病毒性疾病，但感染之后并不会产生永久抗体，所以可能反复感染——尽管还不致在同一天内多次反复。万幸的是，感染后的症状只是不停打嗝，并不会致死。

从首次出现确诊病例那天开始，第 ii 天的确诊病例数记作 xix_i 。借助这一基础数据，便可在选定两个阈值 0≤p<q 0 \le p < q 之后对每一天做风险度评估：对于第 ii 天，我们考查此前 mim_i 天（也就是第 i−mii-m_i 天到第 i−1i-1 天）中单日确诊病例数的最大值 kk ：如果 0≤k<p0 \le k \lt p，就将月球城评定为低风险；如果 p≤k<q p \le k \lt q，评定为中风险；如果 q≤k q \le k，则为高风险。

现在月球城安理会想知道，选用不同的阈值 p,qp, q，低、中、高风险的天数会如何变化。

#### **输入格式**

第一行仅一个正整数 nn，表示考查的天数。 第二行有 nn 个非负整数 xix_i，依次表示每天的确诊人数。 第三行有 nn 个正整数 mim_i，依次列出评估第 ii 天风险时往前追溯的天数。这里约定，第 i−1i-1 天没有追溯到的日子，第 ii 天也不会追溯到——也就是说，必有 mi≤mi−1+1m_i \le m_{i-1} + 1。 第四行仅一个正整数 TT ，表示将尝试 TT 组不同的阈值 p,qp, q 。 接下来的 TT 行各有两个非负整数 pi,qip_i, q_i，即一组阈值。

#### **输出**

共计 TT 行，各有两个整数，对应于低、中风险的天数（高风险不言而喻，不再输出）。

#### **输入样例**

```
7
1 2 3 4 1000 100 20
1 2 3 3 3 4 3
2
3 5
100 200
```

#### **输出样例**

```
3 2
5 0
```

#### **样例解释**

第1天前1天的确诊病例最大值为0，  
 第2天前2天的确诊病例最大值为1，  
 第3天前3天的确诊病例最大值为2，  
 第4天前3天的确诊病例最大值为3，  
 第5天前3天的确诊病例最大值为4，  
 第6天前4天的确诊病例最大值为1000，  
 第7天前3天的确诊病例最大值为1000。

取p = 3, q = 5, 低风险有3天，中风险有2天。  
 取p=100, q=200, 低风险有5天，中风险有0天。

#### **数据范围**

1≤n≤1061 \le n \le 10^6  
 每日确诊人数 xi≤2×106x_i \le 2 \times 10 ^ 6  
 1≤mi<2321 \le m_i \lt 2^{32}  
 1≤T≤1051 \le T \le 10^5  
 0≤pi<qi<2320 \le p_i \lt q_i \lt 2^{32}
