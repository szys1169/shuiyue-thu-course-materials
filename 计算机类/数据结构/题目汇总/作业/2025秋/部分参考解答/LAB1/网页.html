关于二维前缀和算法

二维前缀和算法是一种高效计算二维数组中任意子矩阵元素和的技术。通过预先计算前缀和矩阵，可以将每次查询的时间复杂度从O(n*m)降低到O(1)，非常适合需要多次查询的场景。

算法优势

  • 预处理时间复杂度：O(n*m)
  • 每次查询时间复杂度：O(1)
  • 适合多次查询的场景
  • 内存占用小，只需额外存储两个辅助矩阵

主要步骤

  1. 读取输入矩阵
  2. 计算每行的前缀和(rowsum)
  3. 计算二维前缀和矩阵(matrixsum)
  4. 通过公式快速计算任意子矩阵的和

代码解析 

#include <cstdio>

// 定义全局数组
int matrix[2000][2000];       // 原始矩阵
int rowsum[2000][2000];       // 行前缀和矩阵
long long matrixsum[2000][2000];  // 二维前缀和矩阵

int main() {
    int n, m, q;
    scanf("%d%d", &n, &m);
    
    // 1. 读取原始矩阵数据
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            scanf("%d", &matrix[i][j]);
        }
    }

    // 2. 计算行前缀和
    for (int i = 1; i <= n; ++i) {
        rowsum[i][0] = 0;  // 每行第0列初始化为0
        for (int j = 1; j <= m; ++j) {
            // 当前位置的行前缀和 = 前一列的行前缀和 + 当前元素值
            rowsum[i][j] = rowsum[i][j - 1] + matrix[i][j];
        }
    }

    // 3. 计算二维前缀和
    // 初始化第0行
    for (int i = 0; i <= m; ++i) {
        matrixsum[0][i] = 0;
    }
    
    for (int i = 1; i <= n; ++i) {
        matrixsum[i][0] = 0;  // 每列第0行初始化为0
        for (int j = 1; j <= m; ++j) {
            // 当前位置的二维前缀和 = 上一行的前缀和 + 当前行的前缀和
            matrixsum[i][j] = matrixsum[i-1][j] + rowsum[i][j];
        }
    }

    // 4. 处理查询
    scanf("%d", &q);
    long long sum = 0;
    for (int i = 1; i <= q; ++i) {
        sum = 0;
        int x, y, a, b;
        scanf("%d %d %d %d", &x, &y, &a, &b);
        
        // 核心公式：计算指定区域的和
        sum = matrixsum[x+a-1][y + b - 1] 
            - matrixsum[x + a -1][y - 1]
            - matrixsum[x - 1][y + b - 1]
            + matrixsum[x-1][y-1];
            
        printf("%d\n", sum);
    }
    return 0;
}

核心思想

二维前缀和算法的核心是通过空间换时间，预先计算并存储矩阵的前缀和信息，从而实现快速查询任意子矩阵的元素和。

这种方法特别适用于需要多次查询的场景，能够显著提高程序的运行效率。

复杂度分析

  • 时间复杂度：预处理阶段为O(n×m)，每个查询为O(1)，总复杂度为O(n×m + q)
  • 空间复杂度：O(n×m)，用于存储两个辅助矩阵
  • 优势：当查询次数q很大时，效率提升非常明显
