## 题目描述

以下是大作业的简单介绍（如果已经熟悉这一部分可以跳过）：小明在学习了《程序设计基础》之后，构思了一款模拟机器人搬运积木的游戏。游戏背景是一间未来房间，房间内摆放着积木及两条传送带：输入传送带 会传入一串积木；输出传送带 将积木运走；房间内还设有若干带编号的空地（编号从 0 开始），每个空地最多存放一块积木。房间中有一个机器人。机器人执行一段由多条指令组成的程序来完成任务。每条指令有序号（从 1 开始），机器人默认从第 1 条开始顺序执行。机器人一次只能搬运一个积木，该积木称为 当前积木，初始状态下机器人手中没有积木。机器人的完整指令集定义如下：指令操作数数量功能说明inbox无从输入传送带取一块积木作为当前积木outbox无将当前积木放到输出传送带add X1当前积木的数值 + 空地 X 中积木的数值sub X1当前积木的数值 − 空地 X 中积木的数值copyto X1当前积木复制到空地 Xcopyfrom X1空地 X 的积木复制为当前积木jump X1跳转到第 X 条指令继续执行jumpifzero X1若当前积木为 0，则跳转到第 X 条指令为了在后续大作业中模拟机器人执行过程，你需要首先判断机器人程序中是否存在静态错误。因此，本题要求对给定的一组指令做 静态语法检查，仅检查指令格式是否合法，不模拟运行过程。简便起见，本题中只需要检查指令语法，不需要判断指令能否正常模拟运行。即对于一条指令，若出现以下任意情况，则判定为出错：使用了不在允许集合中的指令名称指令需要操作数但缺少操作数指令不需要操作数却多写了内容操作数不是整数对空地操作（add / sub / copyto / copyfrom）时，操作数不在 [0, 空地数量−1] 范围内对跳转指令（jump / jumpifzero）时，目标行号不在 [1, 指令总数] 范围内若没有出现上述错误，则通过语法检查。注意：本题的输入输出均为文件输入输出！
