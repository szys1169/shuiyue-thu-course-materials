# 报告2中的干涉仪调整与使用两份来源

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人原有副本，保留两份不同字节的填写报告，共3,219,248字节、15文件页。

6页打印件含原理步骤、钠双线干涉、条纹计数、波长和玻璃厚度计算及末页手写原始记录；9页手写件含自制封面、原理步骤、数据不确定度、思考题、私人总结和末页横向打印拟合曲线。只有打印件表头明确物理A(2)，不推广到另一件或授课学期。两份均有私人身份及纸面批改，原文、评价和私人日期只在私有学习目录保存，不在说明中转录。

原文件名、字节、页序、黑边透印和全部记录保持，不裁剪、删页、修订答案，也不认定来源编号代表版次先后或日期代表授课学期。报告2另37份原件仍在原位，不在本组范围内。
