# CST 3-1-3 Feature

---

#### **题目描述**

所谓“线性回归”算法，是对由 nn 个特征 (x1,x2,⋯,xn)(x_1,x_2,\cdots,x_n) 组成的任一样本 xx，输出这些特征的某个“最佳的”线性组合 y=w1x1+w2x2+⋯+wnxny=w_1x_1+w_2x_2+\cdots+w_nx_n，其中 w=(w1,w2,⋯,wn)w=(w_1,w_2,\cdots,w_n) 为权重。我们需要从一组初始权重开始，通过不同的操作修改权重，并计算线性组合的结果。

#### **接口说明**

本题为交互题，我们提供的交互库包括一个头文件 `feature.h` 和一个库文件 `feature_lib.cpp`。前者声明了若干待实现的函数，后者则实现了主函数。在你实现并提交以下函数之后，我们会将库文件和你的程序一起编译、链接：

```
void init(int n, const int *w, const int *x); 
```

特征初始化函数：共有 nn 个特征，编号从 11 到 nn。

ww 和 xx 均是长度为 n+1n+1 的数组，分别存有各特征对应的权重及样本值。

```
void modify_weight(int i, int w); 
```

权重更改函数：将第 ii 个特征的权重修改为 ww。

```
void modify_value(int k, int x); 
```

值更改函数：将权重第 kk 大的特征所对应的样本值修改为 xx。

```
long long calculate(int k); 
```

计算函数：根据权重**绝对值**最大的 kk 个特征（设编号为 i1,i2,⋯,iki_1,i_2,\cdots,i_k），计算输出 y=wi1xi1+wi2xi2+⋯+wikxiky=w_{i_1}x_{i_1}+w_{i_2}x_{i_2}+\cdots+w_{i_k}x_{i_k} 并返回。

这里保证在每次操作的前、后，各特征的**权重绝对值两两不同**。

#### **测试说明**

交互库的具体实现如下：

- 首先从标准输入中读取两个整数：特征总数 nn、操作次数 mm；
- 然后从标准输入中读取每个特征的初始权重和样本值，并调用 `init` 函数；
- 接着从标准输入中依次读取操作的描述信息，并相应地调用`modify_weight`、`modify_value`或`calculate` 函数；并将可能的返回值写到标准输出。

在本地测试阶段，可以命令行：

```
g++ feature_lib.cpp your_code.cpp -std=c++14 -O2 -o feature.exe
```

来编译你的程序，再运行`feature.exe`做测试。

你必须严格按照格式来向交互库输入数据，否则不能保证交互库正常运行。输入完成后，在 cmd 或 PowerShell 里，可用Ctrl + Z表示EOF；在 bash 里，可以用Ctrl + D表示 EOF。

程序运行结束后，将标准输出中的内容与答案做一比较，便可知道你的输出是否正确。

另一个样例程序`feature_sample.cpp`实现了“每次计算操作都报告随机数”的算法。你可以参考该程序来理解交互库和解题，也可以不参考，毕竟这不影响最终得分。

请注意，你只需提交实现了四个函数的源文件，不要提交交互库`feature.h`、`feature_lib.cpp`等其他文件，否则可能会导致编译错误。

交互库和运行库会使用一定时间、空间，且这部分空间会计入评测结果。我们保证交互库消耗的时间不超过0.1sec，消耗的空间不超过(8*n)字节 + 14 MB。

#### **（交互库）输入格式**

第一行有两个整数：特征总数 nn、操作次数 mm；

随后的nn行各有两个整数：第ii个特征的初始权重wiw_i，及其样本值xix_i；

接下来的mm行各描述一次操作，格式如下：

```
W i w    //对应于modify_weight(int i, int w)
V k x    //对应于modify_value(int k, int x)
C k      //对应于calculate(int k)
```

#### **（交互库）输出格式**

计算操作依次各输出一行，分别用一个整数给出对应的结果。

#### **限制**
