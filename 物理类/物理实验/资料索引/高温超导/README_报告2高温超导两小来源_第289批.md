# 报告2中的高温超导两份来源

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人原有副本，保留两份不同字节的测量报告，共7,122,824字节、33文件页。

16页件含原理仪器与电路、测量数据和打印曲线、结论思考及末三页附图和手写原始数据；17页件含手写原理步骤、打印数据表和曲线、思考总结及末四页手写原始数据。两份均有私人身份及纸面批改，原文、评价和私人日期只在私有学习目录保存，不在说明中转录。

原文件名、字节、页序、黑边透印和全部记录保持，不裁剪、删页、修订答案，也不认定来源编号代表版次先后或日期代表授课学期。报告2另43份原件（包括另一份较大高温超导资料）仍在原位，不在本组范围内。
