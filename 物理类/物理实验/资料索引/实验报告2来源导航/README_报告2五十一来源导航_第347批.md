# 实验报告二：来源与去向

来源为共享物理资料库“实验报告2”及本人既有副本，共51条原始来源路径、518,993,133字节，已按内容归档。原位置保留分批说明，下面按主题访问。

资料包括填写报告、测量记录、片段、混合附页和综合扫描汇编。51条路径不代表51份独立完整报告；原件连同批注、曲线、纸面批改和附页完整云盘保存，本入口不新增原件Git，作者与学期详见分组说明。

核磁题名材料实际含核磁、霍尔及逸出功附页；438页综合汇编仅查看8页，其余核结构，书签不宜当作可靠完整目录。
