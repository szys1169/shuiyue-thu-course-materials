# 三份瞬态信号来源的新位置

三份共38页的资料已按原名原字节归位，含传输线、超声、数据处理、波形与记录。一份从仪器介绍开始，身份和前文完整性待核；另外两份有填写封面。原件连同批注附页完整云盘保存，本批未新增Git，私人值不转录，编号沿题名、作者学期待核。
