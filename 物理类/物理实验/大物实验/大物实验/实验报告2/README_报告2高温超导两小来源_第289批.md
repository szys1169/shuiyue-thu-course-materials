# 高温超导两份来源的新位置

两份共33页的高温超导测量报告已保留原名原字节归入私有学习目录，含原理、数据表、曲线、思考及手写原始记录与纸面批改。私人身份、评价和日期不在说明中转录；全部记录和附页仍保持，不裁剪或修订答案。

只整理本次两份小来源，来源编号不证明版次先后，也不证明独立报告或授课学期。另43份原件（包括较大的高温超导来源）保持原位。
