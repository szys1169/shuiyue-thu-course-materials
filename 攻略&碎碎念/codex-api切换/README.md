# Codex API 切换工具

> 作者：水至月生  
> 适用系统：Windows  
> 更新日期：2026 年 8 月 29 日

这个工具用来在 Codex 原版、并行智算云和 DeepSeek 官方 API 之间切换。正常情况下不需要手动修改配置文件，也不需要看懂 PowerShell，跟着窗口中的菜单输入数字即可。

如果你只是想尽快用起来，可以直接看下面的“第一次使用”。

## 一、开始之前需要准备什么

请先确认下面三件事：

1. 已经安装并至少打开过一次 ChatGPT 桌面应用或 Codex；
2. 电脑是 Windows 系统；
3. 如果准备使用并行智算云或 DeepSeek，手里已经有对应平台的 API Key。

API Key 是一串调用凭证，作用有点像密码。并行智算云的 Key 可以在领取校园算力券后，按平台说明创建。DeepSeek 的 Key 则需要在 DeepSeek 官方 API 平台创建。

不同平台的 Key 不能混用。并行智算云的 Key 要填到并行智算云选项，DeepSeek 的 Key 要填到 DeepSeek 选项。

## 二、下载与解压

如果你拿到的是 `codex-api切换.zip`：

1. 右键压缩包，选择“全部解压缩”；
2. 打开解压后的 `codex-api切换` 文件夹；
3. 不要只把其中某一个文件拖出来，四个文件需要放在同一个文件夹中。

文件夹里应当有下面这些文件：

| 文件 | 作用 |
| --- | --- |
| `启动Codex切换.bat` | 普通用户双击这个文件 |
| `switch-codex.ps1` | 真正执行切换的脚本 |
| `创建桌面快捷方式.bat` | 可选，用来创建桌面入口 |
| `README.md` | 也就是这份说明 |

## 三、第一次使用

### 第一步：获得 API Key

#### 使用校园算力券

1. 打开[算力券申领平台](https://easycompute.cs.tsinghua.edu.cn/login)；
2. 通过清华大学统一身份认证登录，使用自己的学号或工作证号；
3. 点击“登录领券 / 使用”按钮；
4. 在“我的优惠券”中确认算力券已经到账；
5. 按页面入口进入对应算力平台；
6. 登录后打开平台内置的“大模型平台使用指南”，按当前页面说明创建 API Key。

平台页面、额度和模型可能调整，所以具体按钮以登录后实际显示为准。创建好 Key 后先复制并保存，后面运行脚本时会用到。脚本已经内置并行智算云的 Base URL 和模型名称，不需要自己手动填写。

#### 使用 DeepSeek 官方 API

进入 [DeepSeek API Key 页面](https://platform.deepseek.com/api_keys)，登录后创建 Key。DeepSeek 的额度和计费与校园算力券无关，需要在 DeepSeek 平台单独查看。

无论使用哪一个平台，都不要把 Key 发到群聊，也不要让它出现在截图里。建议临时保存在可靠的密码管理器中。

如果暂时没有任何 API Key，也可以运行工具并选择 `3`，恢复或使用 Codex 原版。

### 第二步：关闭 Codex

切换前先保存正在编辑的内容，再完全退出 ChatGPT 桌面应用、Codex CLI 或 VS Code 中正在运行的 Codex 会话。这样重新打开时会直接读取新配置。

### 第三步：启动工具

双击 `启动Codex切换.bat`，之后会出现一个黑色窗口。看到下面的菜单后，输入对应数字并按回车：

```text
========== Codex 后端切换 ==========

 1) DeepSeek 官方
 2) 并行智算云
 3) Codex 原版
 0) 退出
```

我更推荐有校园额度的用户先选择 `2`。如果使用 DeepSeek 官方 API，则选择 `1`。想恢复 ChatGPT 账号对应的 Codex 原版配置时，选择 `3`。

### 第四步：选择模型

选择并行智算云或 DeepSeek 后，窗口会继续让你选择模型。输入模型前面的数字并按回车即可。

模型名称和平台支持情况可能变化。如果之后提示模型不存在，可以先换另一个模型，或者参考“常见问题”中的处理方法。

### 第五步：输入 API Key

第一次使用某个平台时，工具会提示输入 API Key。粘贴后窗口里不会显示星号，也不会显示你输入的字符，这是正常现象，不代表没有粘贴成功。粘贴完成后直接按回车。

以后再次选择同一平台时，可以选择使用上次保存的 Key，也可以重新输入一个新的 Key。

### 第六步：重新打开 Codex

看到 `[OK] 已切换到……` 后，关闭黑色窗口，再重新打开 ChatGPT 桌面应用、Codex CLI 或 VS Code。

桌面应用的模型位置可能显示具体模型名，也可能显示 `Custom`。先发送一个很短的测试任务，例如：

```text
请只回复“连接成功”，不要读取或修改任何文件。
```

能够正常返回内容，基本就说明接口已经接通。之后再开始较长任务，避免配置还没成功就重复消耗额度。

## 四、以后怎样快速切换

如果不想每次进入文件夹，可以双击 `创建桌面快捷方式.bat`。桌面上会出现“Codex切换”图标，以后双击这个图标即可打开菜单。

创建快捷方式不是必需步骤，也不会把整个工具安装进系统。请不要移动或删除原文件夹，否则桌面快捷方式会失效。

## 五、三种选项分别是什么

| 选项 | 适合谁 | 是否需要额外 Key |
| --- | --- | --- |
| DeepSeek 官方 | 已经在 DeepSeek API 平台充值或领取额度的用户 | 需要 DeepSeek API Key |
| 并行智算云 | 有校园算力额度，希望尽量降低成本的用户 | 需要并行智算云 API Key |
| Codex 原版 | 使用 ChatGPT 账号或 OpenAI 官方方式的用户 | 切换脚本中不需要输入 Key |

切换到第三方 API 后，模型能力、可用工具、上下文长度和稳定性都由对应平台与模型共同决定，不一定和 Codex 原版完全一致。

## 六、常见问题

### 双击以后窗口一闪而过

先确认压缩包已经完整解压，并且 `启动Codex切换.bat` 和 `switch-codex.ps1` 仍在同一个文件夹。不要直接在压缩包预览窗口里运行。

仍然无法启动时，可以右键 `启动Codex切换.bat`，选择“以管理员身份运行”。一般情况下并不需要管理员权限，所以只在普通双击失败后尝试。

### Windows 提示文件来自其他计算机

先确认文件确实来自本文附件，而不是群聊中的未知二次打包。确认来源后，可以右键文件打开“属性”，勾选“解除锁定”再运行。如果无法确认来源，先不要运行。

### 输入 API Key 时没有任何显示

这是脚本为了避免旁边的人直接看到 Key 而采用的隐藏输入。正常粘贴并按回车即可。

### 切换成功，但 Codex 仍然使用原来的模型

完全退出并重新打开 ChatGPT 桌面应用。VS Code 中的 Codex 扩展和已经打开的命令行会话也需要重新启动。

### 切换后以前的聊天记录不见了

不同登录方式或模型提供商的会话可能会分开显示，原记录通常没有被删除。重新切换到原来的后端并重启 Codex 后再检查。

### 提示模型不存在

平台的模型 ID 可能已经更新。普通用户可以先换另一个模型；熟悉 PowerShell 的用户可以用后面的 `list-models` 命令查询平台当前返回的模型 ID，再修改脚本开头的 `$Backends`。

### 想恢复 Codex 原版

重新运行工具，在第一个菜单里输入 `3`。工具会删除自己添加的第三方后端配置，并恢复 Codex 原版所需的主要配置项。之后仍然要重启 Codex。

### 配置真的改坏了怎么办

每次切换前，脚本都会把原来的配置备份到：

```text
%USERPROFILE%\.codex\backup-switch
```

这里的文件名包含备份时间。需要手动恢复时，先关闭 Codex，再把合适的备份复制回 `%USERPROFILE%\.codex\config.toml`。如果不确定应该选哪一份，可以把报错和备份文件列表发给熟悉配置的人看，不要直接删除整个 `.codex` 文件夹。

## 七、API Key 保存在什么地方

为了让下次切换时可以直接复用，工具会把 Key 保存在当前 Windows 用户的环境变量与下面这个本地文件中：

```text
%USERPROFILE%\.codex\.codex-switch-keys.json
```

当前正在使用的第三方 Key 也会写入：

```text
%USERPROFILE%\.codex\config.toml
```

脚本会尝试限制 Key 文件的访问权限，但这些位置仍然是本机明文配置，不适合多人共用或不受信任的电脑。不要分享 `.codex` 文件夹，也不要把其中的配置上传到 GitHub。Key 一旦泄露，应立即到对应平台撤销并重新生成。

## 八、命令行用法

这一节给需要排查问题或进行高级操作的用户，普通使用可以跳过。

在工具文件夹中打开 PowerShell 后，可以运行：

```powershell
.\switch-codex.ps1 start
.\switch-codex.ps1 status
.\switch-codex.ps1 setkey paratera
.\switch-codex.ps1 setkey deepseek
.\switch-codex.ps1 list-models paratera
.\switch-codex.ps1 list-models deepseek
```

- `start`：打开交互式切换菜单；
- `status`：查看当前后端和模型，Key 只会显示一小部分；
- `setkey`：单独保存或更新某个平台的 Key；
- `list-models`：查询平台当前返回的模型 ID。
