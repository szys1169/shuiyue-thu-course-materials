# 报告2中的偏振光学两份小来源

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人原有副本，保留两份不同字节的手写填写报告，共8,509,096字节、31文件页。

16页件含自制封面、偏振原理、仪器步骤、波片和偏振测量、数据处理与思考，第15页是原始记录纸，第16页是打印曲线；15页件同样含原理、仪器、测量记录和结果分析，末页为打印曲线。两份均有私人身份及纸面批改，原文、评价和私人日期只在私有学习目录保存，不在说明中转录。

原文件名、字节、页序、黑边透印和全部记录保持，不裁剪、删页、修订答案，也不认定来源编号代表版次先后或日期代表授课学期。报告2另31份原件（包括另两份偏振题名资料）仍在原位，不在本组范围内。
