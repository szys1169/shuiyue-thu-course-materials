# 数学分析资料来源与整理说明

云盘目录：数学分析

更新日期：2026-10-18；第2批补全。

本目录及子目录保留学习文件283份，其中常用学习目录277份。旧版本与重复副本放在“_过程材料/旧版”；原作者说明README.txt保留。

## 来源与版本说明
- 第1批保留83份学习资料；第2批整理个人云盘原习题课及小班辅导80份（其中1份为原有重复副本），新增120份不同内容资料。常用目录保留277份，旧版/重复副本6份，另保留原README.txt。
- 第2批共核对221条来源记录：网络学堂134条、致理书院87条；新增网络学堂49份、致理书院71份，其余101条与已有资料或本批其他来源内容重复，未重复导入。
- 网络学堂来源为本人已修数学分析(1)(2)(3)课程：2024-2025秋、2024-2025春、2025-2026秋，课程教师卢旭光。习题解答作者以原文件署名为准。网页条目标题用于生成文件名，下载原名、条目ID、发布日期记录在批次清单。
- 文件夹“2024秋/2025春/2025秋”表示课程所在学期；不将某文件的发布日期、年级或讲义版本号一概改写为考试年份。
- 教师讲义按课程学期保留；同一学期同章节明确的较早版本放入“_过程材料/旧版”。已有2024级通用讲义未覆盖，课程修订版在对应学期目录中保留，来源与版本可逐项追溯。
- 习题课中同次课但内容不同的文件分别保留；不将题目与解答强行合并。原“第9次习题课解答 (1).pdf”与无后缀版本内容相同，前者已归档备查。
- 致理书院来源：致理学生会学习部共享网盘→【只读】学习资料→数学类→数学分析，包括2023秋/2024春-cdg、张友金老师及其2021春目录。cdg课程教师根据原目录及同目录试卷标注识别为陈大广；各文件原作者以文件内容为准。
- 于品/张友金署名讲义按署名归类；没有明确学期的资料放“学期未标注”。“9字班”等原班级标记不推断实际年份。两个同名的9字班期中题内容不同，已加来源后缀区分。
- 复习范围、样卷、课程待核实材料延续第1批分类；例如2007春高等分析.doc仍不认定为数学分析正式试卷。
- 作业目录中的第十三、十四章个人解答作者为水至月生，原README.txt完整保留；不归属为教师标准答案。
- 本批未搬迁教材/参考书。网络学堂数分三中的“下学期测度与积分讲义”未纳入数学分析；数分二课程中发布的Fubini定理证明作为该课补充专题保留。
- 源云盘、本地历史资料均保留；未上传整包ZIP。原“卢旭光老师”剩余教材、独立习题，以及课程根数分.pdf保持原位置。
