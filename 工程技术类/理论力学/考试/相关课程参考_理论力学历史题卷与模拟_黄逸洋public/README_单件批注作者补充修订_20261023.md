# 单件批注作者补充修订

本组资料来源于黄逸洋公开共享云盘。来源原说明与原来源清单继续保留；本说明仅补充下述单件的当前整理方式。

`理论力学-2018秋期末-马逸_去批注作者账号整理副本.pdf` 对应来源的 2018–2019 秋期末 A 卷参考答案及评分标准，共 11 页。仅清空第 4 页三条批注中的作者账号元数据；该字段为批注账号，不能据此认定为学号。题目、答案、分值、批注图形和批注文字均未改写。

副本经逐对象、原始及解码内容流、全部 11 页文本和逐页像素比对。原件保留，未用副本覆盖。副本 SHA-256 见同目录补充清单，原件指纹留私有验收台账。此修订不代表来源答案正确性已校验。
