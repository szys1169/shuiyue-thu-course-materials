# 三卷中译本：来源扫描

来源：清华云盘物理库“大学物理学基础”原有三卷扫描PDF。本次归入既有大学物理教材体系，原文件名、页面、扫描印章及手写标记、字节全部保持。三卷均署M. Alonso、E. J. Finn合著，梁宝洪译；扫描PDF共2031页、33,223,704字节。书目依据各卷扉页和版权页目视，文件名作为来源标签另列，不能替代版权证据。

原件仅存私有学习目录，Git只同步来源及书目索引。扫描多数页面无可提取正文，本次核对前部版权及目录样张，不是逐页校订2031页，也不保证扫描无缺页；不补扫、不转换、不改名。所有权利归原作者及出版者，整理不授予额外许可。
