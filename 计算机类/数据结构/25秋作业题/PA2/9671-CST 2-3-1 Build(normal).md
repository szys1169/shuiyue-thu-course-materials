# CST 2-3-1 Build(normal)

---

### **描述**

#### **多叉树与孩子节点表示法**

由 NN 个节点构成的一棵多叉树，可用**孩子节点表示法**（05-A2 节）来存储，例如下面这棵多叉树

![](../附件/40e811a385be3d1669349ea36b86910b14bfe882.png)

可表示为：

```
3 3 2 4
3 8 6 7
1 5
0
0
0
0
0
```

其中的第 ii 行对应于第 ii 个节点（1≤i≤N1 \le i \le N）：首先是一个非负整数 did_i，即该节点孩子的数目；随后是 did_i 个正整数，按图示从左到右的次序逐一列出孩子节点的编号。根节点的编号固定为 11。

#### **节点、子树与通路表示法**

除了用编号来对应节点，我们还可以用从根节点通往各节点的那条唯一的通路来分别表示它们（以及以它们为根的子树），比如上例中的节点 77 就可以表示为：

```
2 1 2
```

其中，第一个非负整数为通路的长度 mm（22），随后的 mm 个非负整数依次列出了通路上各个节点在（亲）兄弟中的**排行**次序（rank，从 00 开始）：先从根节点转向它的第 11 个孩子（节点 22），再从节点 22 转向它的第 22 个孩子（节点 77）。

当然，反过来，**形式上**合法的这样一行数字，未必是**实际上**合法的：对应于一条真实存在的通路（及其终点）。以下就是这样的一例：

```
3 1 2 3
```

这行的第一个整数 33 意味着一条长度为 33 的通路，而上图所示的多叉树高度仅为 22 ，故这条通路并不存在。再如：

```
2 0 1
```

虽然根节点有长子（第 00 个孩子，节点 33），但节点 33 并没有次子（第 11 个孩子）。

我们约定，**形式上**合法的任何一条通路，都等效地被理解为其**实际上**合法的最长前缀。于是，上述实例中的两条通路，依然可以分别理解为与节点 77、节点 33 相对应。

#### **子树移动**

所谓的在多叉树中将某一棵**真**子树 ss **移动**到目标位置 (d,k)(d,k)，是指先将 ss 从树中分离出来（类似于 05-B2 节的 `Bintree::secede()`），再将其接入到节点 dd 下面，作为 dd 的第 kk 个孩子（类似于 05-B2 节的 `BinTree::attach()`）。

这里约定，ss 和 dd 均用**通路表示法**来指定；kk 则用一个非负整数来指定。

仍以上面的多叉树为例，将子树 ss：

```
2 0 0
```

移动到节点 dd：

```
1 1
```

之下作为孩子，且排行 kk 为：

```
0
```

多叉树将相应地演变为：

![](../附件/5233545de6add4c06800a2f102368dd27c85db86.png)

为消除当 `s->parent == d` 时可能的歧义，这里约定：kk 是就 ss **刚分离之后**的时刻而言的。此外，dd 的通路表示也是就 ss 分离后的时刻而言的。

比如对于最初的实例，将子树 ss：

```
2 1 1
```

移动到节点 dd：

```
1 1
```

之下作为孩子，且排行 kk 为：

```
2
```

所得到的多叉树应为：

![](../附件/b0adebe45efbac5349fdb8e9973892f0b1e85f74.png)

每次子树移动操作的**成本**，等于节点 ss 和 dd 按照**通路表示法**所对应的两行中所有整数的总和，再加上 kk 。比如，上例中操作的成本为： (2+1+1)+(1+1)+2=8 (2 + 1 + 1) + (1 + 1) + 2 = 8

### **输入**

第一行为两个整数：NN（多叉树中的节点总数）、MM（移动操作的次数）。

随后的 NN 行，以**孩子节点表示法**给出一棵多叉树。

接下来的各行，依次描述 MM 次移动操作，以连续的 33 行描述：第一行指定源子树 ss；第二行和第三行指定移动的目标位置 (d,k)(d, k)。

### **输出**

共 NN 行，表示按顺序经过所有移动操作后的多叉树的层次遍历，每行对应一个节点。

### **输入样例**

```
8 1
3 3 2 4
3 8 6 7
1 5
0
0
0
0
0
3 0 0 2
3 1 2 3
0
```

### **输出样例**

```
1
3
2
4
8
6
7
5
```

### **限制**

1≤N≤1061 \le N \le 10^6

1≤M≤1041 \le M \le 10^4

所有操作的**成本**之和不超过 10610^6。

时间：2.5 sec

空间：256 MB

本题**不限制**栈空间大小。

**本题允许使用STL**

### **提示**

- 子树的分离、接入过程中，可能需要遍历和移动大量的节点，因此需要用心设计孩子节点的存储方式，把复杂度控制在**成本**范围以内。
