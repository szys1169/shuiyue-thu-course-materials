# 瞬态信号测量的三份来源

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本，共三份PDF、15,009,354字节、38文件页，内容涉及示波器、传输线脉冲反射、超声测量、数据处理与曲线。

原件连同批注、附页、波形和数据完整云盘保存，本批未新增入Git。身份、私人日期及评价不在说明中转录；编号沿原题名，作者、学期待核。报告2另15份原件保持原位。
