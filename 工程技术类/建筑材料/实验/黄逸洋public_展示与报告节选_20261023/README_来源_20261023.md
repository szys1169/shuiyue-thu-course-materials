# 展示与报告节选

来源：[黄逸洋public建筑材料实验](https://cloud.tsinghua.edu.cn/d/cc494ee97f884a3b9ffb/?p=%2F2.7_%E5%9C%9F%E6%9C%A8%E7%B1%BB_%E5%BB%BA%E7%AD%91%E6%9D%90%E6%96%99%2F%E5%BB%BA%E7%AD%91%E6%9D%90%E6%96%99%E5%AE%9E%E9%AA%8C_%E9%A9%AC%E9%80%B8&mode=list)。

混凝土性能与自密实配合比两份展示，以及3份单页报告节选。节选保留原页码、普通署名、图表和演算，不称完整独立报告或教师标准答案。

本组逐件进行了只读文本、结构及元数据核对，PDF按首末页或单页有限目视。普通作者署名保持。另有含学生编号的报告和班级名单仅留整理过程，未混入本组。
