## 代码01
1.错误类型：Runtime Error
2.错误原因：在计算连续消除时没有考虑边界，导致left可能取到-1
3.测例：
A
3
0 A
0 A
0 A
答案：A
4.构造思路：考虑在0处发射，触发消除，在0处触发消除后的连消判定后，left从0向左移动，指向-1，引发错误

除此错误外，代码02的错误也适用于代码01

## 代码02
1.错误类型：Runtime Error
2.错误原因：在计算连续消除时没有考虑字符串是否为空，导致可能访问空字符串
3.测例：
A
3
0 A
0 A
0 A
答案：A
4.构造思路：考虑在0处发射，触发消除，在0处触发消除后的连消判定后，left移动到0，但是此时字符串为空，引发错误

## 代码03
1.错误类型：Time Limit Exceeded
2.错误原因：时间复杂度较高，在规定数据内会超时（插入时间复杂度$o(n)$，m次时间复杂度为$O(mn)$）
4.构造思路：考虑构建一个超大数据组，并且尽可能提高时间复杂度，从而使程序超过时间限制(取m=400000，n=200000，操作次数大于$8*10^10$，按照每秒10^9基础运算，该程序超时)

## 代码04
1.错误类型：Wrong Answer 
2.错误原因：在考虑消除的时候没有具体计算左边界，导致左边界失效
3.测例：
BAB
1
2 A
答案：BAAB
4.构造思路：考虑构建一个“BA+A”式的情况，这时候由于不考虑左边界，不该触发消除，但是触发了消除

## 代码05
1.错误类型：Wrong Answer 
2.错误原因：输入时使用了cin，导致无法识别空行
3.测例：

1
0 A
答案：A
4.构造思路：初始序列为空的序列，则会把操作步数识别为最初序列，后插入0位置识别为步骤数为0，导致输出操作步数

## 代码06
1.错误类型：Wrong Answer 
2.错误原因：没有检查每块存储的数据，导致超出存储范围后没有重组，导致多次插入可能超过存储范围

4.构造思路：构建初始序列恰为一个块+一个字符，第一个块内全为AB交替，第二个块内字符为C，之后向第一个块内不断插入直到数据长度为4096，再次插入后，由于数据超过存储范围，会越界覆写的第二个块的数据，导致第二个块内数据C变为B（第一块内最后一个元素），从而在输出时，该输出C时输出B，答案错误

## 代码07
1.错误类型：Wrong Answer 
2.错误原因：计算需要消除的区间的时候，如果left小于0只考虑左移一个块，导致部分情况漏判

4.构造思路：构造多个块为0的情况，之后在这些空块左右构造一个三消（右边插入），在计算需要消除区域的时候，由于空块阻碍导致不能消除

## 代码09
1.错误类型：Runtime Error
2.错误原因：消除只考虑不同块消除的情况
3.测例：
ABBA
1
2 B
答案：AA
4.构造思路：考虑构建一个同块相除的情况，让其出错，输入B后，消除把块的长度更新为负数，进而在p转化为a时出错
