# 弗兰克—赫兹实验三份资料的新位置

本目录中本次所选三个来源路径已保留原文件名和字节，移入私有学习目录。三份共32文件页，包含手写与排版报告、曲线、原始记录和仪器打印图，个人身份及评价不在说明中公开。

原件不裁剪、补页或拆分；不同文件保留，不按编号认新旧或教师标准答案。只有8页件表头明确标注物理A(2)，不能扩展到其它件或据私人日期认定学期。另48份资料（含另一同题名来源）仍在原位。
