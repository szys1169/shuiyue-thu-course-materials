# 空气折射率三份来源的新位置

三份共17页的空气折射率填写报告已保留原名原字节归入私有学习目录，含原理步骤、数据处理、思考小结、原始记录与纸面批改。私人身份、评价和日期不在说明中转录；部分空白与已填记录混合的末页仍保持，不拆为净题纸，不裁剪或修订答案。

只整理本次三份小来源，来源编号不证明版次先后，也不证明独立报告或授课学期。另40份原件（包括不同拼写的另一折射率来源及两份仪器调整资料）保持原位。
