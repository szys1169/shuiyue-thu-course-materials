# 微波光学来源

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本份PDF为6,298,000字节、2文件页，含微波波长、晶体布拉格衍射的目的原理、实验步骤及波长测量数表和误差分析。本件只见两页内容，保留为填写片段，不认完整覆盖题中所列全部实验。

原件连同批注、照片顶边、阴影、页边和附页完整云盘保存，本批未新增入Git。身份、私人日期及评价不在说明中转录，原题名保持，作者、学期待核。

本组仅整理这一条来源路径，报告2另5份原件保持原位。
