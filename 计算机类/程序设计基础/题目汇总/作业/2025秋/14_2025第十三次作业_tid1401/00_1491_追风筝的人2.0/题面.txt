追风筝的人2.0
时间限制： ms
内存限制： MB

题目描述
追风筝的人有一种特殊的嗅觉，无论风往哪个方向吹，都能知道风筝落在哪。他要做的只是奔跑，沿着一条最短路。开始时，追风筝的人处在(0,0)点，风筝在(n,m)点，给出h[i,j]表示追风筝的人从(i,j)跑到(i+1,j)所需的时间，还给出v[i,j]表示追风筝的人从(i,j)跑到(i,j+1)所需的时间。现在，请你求出追风筝的人跑到风筝落点所需要的最少时间。

输入描述
第一行两个正整数n和m，以空格隔开。随后是 n行 m+1列 的矩阵（即n行，每行m+1个正整数），其中第i行第j列表示h[i-1,j-1]。随后是 n+1行 m列 的矩阵（即n+1行，每行m个正整数），其中第i行第j列表示v[i-1,j-1]。

输出描述
一行，一个正整数，表示最少需要的时间。

样例输入
2 2
9 7 10
7 1 9
1 7
8 7
8 4

样例输出
13

注释
【数据规模】0 < n, m<=10000 <= h[i,j], v[i,j] <= 1000总时间在int范围内注：输入数据量偏大，若用cin, cout的同学，可使用下面语句关闭与stdio的同步：int main() {
  ios::sync_with_stdio(false);  // 在这里设置一次就可以。

  // do what you want
  int n, m;
  cin >> n >> m;
  // ...
  return 0;
}
