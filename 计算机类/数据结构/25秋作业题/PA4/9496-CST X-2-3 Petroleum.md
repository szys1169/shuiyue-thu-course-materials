# CST X-2-3 Petroleum

---

### **题目描述**

小明经营了一家石油公司，最近新勘探到一片油田需要开采。

石油开采时需要向下钻井，石油井必须保持竖直向下，否则会有塌方的危险。 石油井挖出石油以后必须停止向下挖，也就是说如果一块石油区域上方全被其他石油区域遮挡住，那么这块石油区域就无法开采。 由于开采能力有限，公司挖掘的石油井最多只能达到 hh 的深度。

油田中的石油分布不均，小明使用了一种最新的勘探仪器，能够获取每一片石油区域的具体位置。 仪器检测到的每一片石油区域都是一个矩形形状，不同的石油区域可能会有重叠。 多个重叠的石油区域是连通的，整体构成了一片大的石油区域，钻到其中任意一片就可以把区域中所有的石油都抽出来。

以下图为例，图中A块可被直接挖出。B块正上方完全被遮挡住，所以无法开采。C块未被遮挡，但是本身处于深度 hh 以下，所以无法开采。 DEF三块联通，且F块可以被开采，所以这三块组成的联通区域均可被开采。

![](../附件/5975ef6da3f138a38c0c4f526780fae3360a7f1d.png)

由于每天都能勘探到新的石油区域，小明希望请你帮忙参与制定公司的开采计划。

### **输入**

第一行为两个正整数，深度限制 hh 和一个正整数 NN，最小深度小于等于 hh 的石油区域才能被石油井挖到。 接下来的 NN 行，包含以下三种格式的事件：

1. A x1 y1 x2 y2A\ x1\ y1\ x2\ y2，表示新勘探到了一块矩形石油区域，两个顶点坐标分别为(x1,y1)(x1, y1) 和 (x2,y2)(x2, y2)。坐标均为非负整数，yy 表示离地面的深度，输入保证 x1≤x2,y1≤y2x1 \leq x2, y1 \leq y2。
2. QQ -1，输出一个数量 mm, mm 表示当前最少需要多少口石油井才能开采出所有能开采的石油区域。
3. Q tQ\ t，输出勘探到的第 t+1t+1 块石油区域是否能被开采，能则输出 YesYes，否则输出 NoNo。输入保证 tt 大于等于零且小于当前已勘探到的区域数量。

### **边界情况说明**

1. 坐标含义：每一个整数表示一个格点，例如下图中的区域A，其坐标表示为 0 0 2 10\ 0\ 2\ 1，可以在 x=0,1,2x=0,1,2 三个位置打井挖出区域A的石油。
2. 可开采区域：最小深度小于等于 hh 的区域可以被开采，如下图中的区域D所示。
3. 区域连通：只有重叠的区域是连通的，边界紧邻的区域不是连通的，例如下图中的区域A,B,C是互相不连通的。

![](../附件/5ec2177e5337a993fca2764d9ddae3c9306cba96.png)
