# 逸出功测量的两份来源

来自共享物理资料库“实验报告2”及本人旧副本。本组两份各13页，共22,927,619字节，均为已填写的个人实验报告。

第一来源含原理、仪器电路、填写数据表、拟合图、误差分析和总结；首页及部分附图可见身份填写或署名。第二来源含原理、测量表、拟合图、讨论问答与原始数据表，前页身份栏为空，后部图表仍可见署名。

原件连同整件页序、手写改动和图表完整云盘保存，本批不新增原件Git，具体个人字段不转录。作者、课程学期及计算正确性未核，现有页面不用于证明原提交附件齐全。另一份8页逸出功来源仍在原位。
