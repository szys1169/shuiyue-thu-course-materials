## 题目描述

已知一个一元二次方程的系数为 a、b、c，且判别式大于零（即有两个不同的实根）。请编写一个程序，计算并输出这两个实根，结果保留 3 位小数。输出的两个根按 从小到大 的顺序排列，中间用空格分隔。

## 输入描述

无输入，三个方程的三组a、b、c按顺序分别取以下值：   

 1.a = 1, b = -3, c = 2  
 
  2.a = 2, b = -5, c = 2  
   
  3.a = -3, b = 10, c = 2

## 输出描述

三行，每行两个实数，按上述系数a、b、c顺序表示方程的两个不同实根，保留 3 位小数，按从小到大顺序输出，中间用空格分隔。
