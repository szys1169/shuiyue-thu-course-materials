# 报告2中的空气折射率三份来源

本组来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人原有副本，保留三份不同字节的填写报告，共4,025,686字节、17文件页。

一份5页打印排版稿含原理步骤、数据处理和末页手写原始数据；一份7页手写稿含原理、数据、思考、小结及末页混合填写表；另一份5页手写稿含原理、不确定度处理、思考与末页原始数据。三份均有私人身份及纸面批改，原文、评价和私人日期只私有保留，不在说明中转录。末页部分空白栏与已填记录整件保留，不拆为净题纸。只有打印稿表头明确物理A(2)，不推广到其它件或授课学期。

原文件名、字节、页序、黑边透印和全部记录保持，不裁剪、删页、修订答案，也不认定来源编号代表版次先后或日期代表授课学期。报告2另40份原件（包括不同拼写的另一空气折射率来源及两份仪器调整资料）仍在原位，不在本组范围内。
