## 同步规则

- 单个新增文件不超过 10 MiB。
- 不同步视频、音频、PPT、课本、教材、讲义、整套课件及大型压缩包。
- 不同步虚拟环境、IDE 缓存、构建目录、可执行文件、模型文件等生成内容。
- 源码配套的 Makefile、Qt 工程/界面/资源清单、图片和样例输入输出按原相对路径保留；文本 `.out` 样例不视为可执行文件。
- PDF 仅在路径或名称可识别为往年题、作业、习题、答案、笔记、总结或课程报告时同步。
- 未同步项目记录在对应目录的 `云盘未同步文件清单.md` 中。

初始扫描同步 1,552 个小文件，合计约 824.85 MiB；排除 1,120 个文件或整目录，已知排除体积约 14.57 GiB。
