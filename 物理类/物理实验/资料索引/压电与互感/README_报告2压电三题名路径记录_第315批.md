# 压电原题名三条来源路径

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本批末一份为9页彩色照片填写稿，含原理步骤、数据处理、思考题、横向导纳曲线和个人总结，其中一页为空栏原始表，与整件共同保存。

原件连同批注、页边阴影、曲线及附页完整云盘保存，本批未新增入Git。身份、私人日期和评价不在说明中转录；编号沿原题名，作者、学期待核。

三个原题名路径均有去向记录，共44,584,679字节、36文件页、3个不同SHA。前两份沿用第313批已验来源与已保存云盘字节，本批新回取末一份，本地三件重新核对哈希。前批16页件含压电与互感混合内容，此账只记录来源去向，不是三份纯压电独立报告或新版。报告2另20份原件保持原位。
