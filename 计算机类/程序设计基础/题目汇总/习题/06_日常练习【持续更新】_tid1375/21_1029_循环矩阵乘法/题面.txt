循环矩阵乘法
时间限制： ms
内存限制： MB

题目描述
给定一个循环矩阵，求其自乘结果。
 
仅仅需要求出自乘后矩阵其中Q行的结果，行和列均从0开始标号。
 
n阶循环矩阵A定义为：令a为n元行向量，ai为a循环右移n位的新向量。则A=[a0,a1,...,an-1]T

输入描述
第一行一个数n，表示矩阵的阶数。
 
第二行一个数Q，表示要求输出的行数。
 
第三行Q个数{qi}，表示依次输出新矩阵的哪些行。
 
接下来n行，表示矩阵A，保证A是循环的。

输出描述
Q行，依次为新矩阵的{qi}行。

样例输入

&nbsp;
2
&nbsp;
2
&nbsp;
0 1
&nbsp;
0 0
&nbsp;
0 0



样例输出

&nbsp;
0 0
&nbsp;
0 0
&nbsp;




注释
数据规模和约定】
 
数据保证有梯度。
 
对于100%的数据，n<=5000,Q<=100,每个元素<=500
