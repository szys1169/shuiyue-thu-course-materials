# 黄逸洋public建筑材料来源导航

来源：[黄逸洋public建筑材料](https://cloud.tsinghua.edu.cn/d/cc494ee97f884a3b9ffb/?p=%2F2.7_%E5%9C%9F%E6%9C%A8%E7%B1%BB_%E5%BB%BA%E7%AD%91%E6%9D%90%E6%96%99&mode=list)。课程材料与建筑材料实验分别按实际内容归类，原收集目录的署名不自动视为每件作者。

本次盘点300条原始文件路径：258条学习材料路径按精确SHA合并为138原件并保留来源别名；33条含学生编号的报告或班级名单（22种字节）仅留整理过程待核，9条系统记录跳过。普通署名、教学联系和出版书目信息随原件保持。

18个来源组包含中英文讲义、作业参考、模拟与概念题、词汇表、实验指导与数据、混凝土专题论文及教材。作答、学生展示与报告片段按参考角色标注，不等同教师标准答案；同名异字节和原项目素材分别保存。

两教材据版权页分别为张君等《建筑材料》2008年第一版、Mehta与Monteiro《Concrete: Microstructure, Properties, and Materials》第四版（2014版权）。书目和质量按有限页面抽样核对，未进行全文逐页审校。
