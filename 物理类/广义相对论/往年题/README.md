# 广义相对论往年试题

当前仅已核来源四张单页试卷：2021、2022春各期末与期末前测一份。

来源为清华云盘物理库「广义相对论/往年试题」原有四份单页PDF。各卷题头均General Relativity，正文明确Spring 2021或Spring 2022，并分别标Final Examination或Pre-final/Pre-Final Examination。按卷面年份与角色整理，原文件名、字节、页面均保留。卷面未给出可独立确认的任课教师、学校、具体考试日期或题目作者，均未补写。

四卷只有题目，没有解答或学生作答；Name、Class、Student Number栏均空白。Pre-final只按原题头记为“期末前测”，不据名称认定模拟卷或与期末同卷。总分是卷面题目设置，不是学生实际成绩。PDF生成日期和元属性设备名不作为考试日或教师证据。所有权利归原作者及提供者，整理不授予额外许可。
