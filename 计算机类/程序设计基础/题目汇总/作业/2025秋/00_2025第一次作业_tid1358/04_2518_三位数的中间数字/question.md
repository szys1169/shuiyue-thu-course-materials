## 题目描述

输入一个三位数A和一个一位数B，判断三位数A的中间数字是否为B。

## 输入描述

输入两个整数A, B。(100 <= A <= 999, 0 <= B <= 9)

## 输出描述

如果三位数A的中间数字是B，输出"YES"，否则输出"NO"

## 样例输入

```text
123 3
```

## 样例输出

```text
NO
```

## 提示与说明

123的中间数是2，不是3，所以输出NO。
