# 直流电路设计的四条来源路径

来自共享物理资料库「物理实验/大物实验/大物实验/实验报告2」及本人旧副本。本批末一份为11页照片填写稿，含目的原理、数据处理分析、思考和三页原始记录。

原件连同批注、边栏记录、阴影和附页完整云盘保存，本批未新增Git。编号沿原题名，作者、学期待核。

四条原题名路径共74,168,854字节、48文件页、4个不同SHA，均已记录去向。前三件沿用第329、331批已验来源与云盘保存字节，本批新回取末一件，本地四件重新核对哈希；此账不代表四份独立报告或版次。报告2另7份原件保持原位。
