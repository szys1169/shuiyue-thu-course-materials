# 水文作业题目与参考

来源：黄逸洋public共享目录“水文学_马逸”。

流域产汇流、水文统计、设计洪水与地下水等题目和不同来源参考，原有版本分别保留；包含课堂题图与静态计算源码，未执行、未核数学正确性。

本组按实际来源角色保存58个学习原件或明确标名的整理副本。同字节的其它来源路径在清单中关联；不同字节版本分别保留，原有页序、圈记和批注不改写。来源学期、教师和适用课程以各原件实际说明为准。
