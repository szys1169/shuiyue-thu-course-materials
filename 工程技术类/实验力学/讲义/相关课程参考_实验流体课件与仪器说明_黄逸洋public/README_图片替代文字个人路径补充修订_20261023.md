# 图片替代文字个人路径补充修订

本组来源于黄逸洋公开共享云盘的实验力学目录。已有来源说明与原来源清单保留，作为来源历史记录；下述具名副本为本轮当前整理文件。

本组 2 件副本仅修改 6 个图片替代文字或图片描述元数据字段，把其中实际个人目录及账号路径缩为原图片文件名。原图片文件名、嵌入图片字节、可见正文、批注、图表和公式均保留。ThinkPad、Administrator 及其 ADMINI~1 短名等默认目录不因正则命中而删除。

- `丹迪热线风速仪使用说明_去图片描述个人路径整理副本.docx`
- `实验流体力学第二部分_去图片描述个人路径整理副本.pptx`

Office 副本经逐个包内文件及 XML 元素和属性核对，只有指定 descr 属性改变，图片、媒体、关系、布局及可见文字保持原字节。未运行 Word 或 PowerPoint，不声称全部排版页目视检查。

原件完整保存在课程过程目录，没有覆盖原件。原件指纹和具体私人路径只留私有验收台账，本说明不转录。旧清单仍列原来源名称，当前公开同步以本补充说明和具名副本为准。本说明只说明内容与守恒验证，不表示云端原件撤回或新件上传已经执行。
